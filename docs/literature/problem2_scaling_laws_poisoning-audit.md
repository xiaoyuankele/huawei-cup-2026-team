## 4. 建模建议：先用可检验的最小扩展

文献支持的是“可提出并检验质量/配比扩展”，不是某一个唯一公式。建议先冻结一个最小、可解释、能退化的候选模型：

\[
L=E+A N^{-\alpha}+B\,[D\,q(Q,p)]^{-\beta}+g(p),
\]

其中 `q(Q,p)>0` 是有效数据倍率，`g(p)` 表示仅由领域混合造成的剩余项。为防止尺度任意性，至少加入：

1. `q(Q_ref,p_ref)=1`，并明确 `Q` 的量纲、范围和基准；
2. 若题面要求“质量完美时退化”，应明确写成 `q(1,p)=1` 或相应的退化条件，而不是口头声称；
3. `p_j≥0` 且 `Σ_j p_j=1`；若含交互项，需说明参数化和正则化；
4. 先拟合 B1 的 `E,A,B,α,β`，再逐步加入 `Q` 和 `p`，用嵌套模型比较，而不是一开始把所有变量塞入高阶多项式；
5. 训练、族外、轨迹、文献和半合成数据分层报告，不能把所有行随机混合后只报一个 R²。

如果采用质量作为有效 token，可定义 `D_eff=D·q(Q,p)`；如果采用显式质量项，则要比较两种结构的预测误差、残差结构和跨来源稳健性。模型选择应由独立验证和参数可识别性决定。

## 5. 弹性、替代和互补的正确读法

对正的可变损失部分 `\tilde L=L-E`，参数弹性应写成无量纲形式：

\[
\varepsilon_N=\frac{\partial\ln \tilde L}{\partial\ln N},\qquad
\varepsilon_D=\frac{\partial\ln \tilde L}{\partial\ln D},
\]

若 `L` 随规模增加而下降，这两个数通常为负；也可以报告其绝对值，但必须在表头写清定义。有限差分 `ΔL/ΔN` 只是边际变化率，不能冒充弹性。

在固定 `D,p` 的局部替代分析中，质量与参数的等损失条件来自

\[
\frac{\partial L}{\partial\ln N}d\ln N+\frac{\partial L}{\partial Q}dQ=0,
\]

因此

\[
\frac{d\ln N}{dQ}=-\frac{\partial L/\partial Q}{\partial L/\partial\ln N},
\]

只在局部、其他变量固定、两项导数可识别且模型通过验证时成立。若加入成本函数，还应比较单位成本边际收益，而不是只比较未归一化导数。域间“替代/互补”要用明确的交互项或 Hessian/交叉偏导定义，并通过 bootstrap 或分块重采样给出不确定性；不能由相关系数或隐藏文字中的符号直接判断。

## 6. 建议的阅读—建模—验证顺序

1. 读 Kaplan 与 Hoffmann，冻结 `L,N,D,C` 的变量定义和经典基线。
2. 读 RegMix、DoReMi、Data Mixing Laws，确定 `p` 的 simplex 表示、域级损失和未见配比验证方式。
3. 读 Chang 等质量感知工作，再决定 `Q` 是有效 token 倍率、显式项，还是两者的敏感性对照。
4. 用 B1 做主拟合；B2/B3 做轨迹与族外检查；B4/B5 做外部/文献验证；B6–B8 只做半合成补充。
5. 报告参数、置信区间/自助法、残差诊断、跨来源误差和外推边界；不要用训练 R² 代替验证。
6. 最后再计算弹性、等损失替代率和 `p` 的交互效应，并把每一项回链到 run_id 和 claim ledger。

## 13. B8 方向差异的结构性证据

在固定 `(N,D)` 的组内比较 `Q` 斜率后，B6 的 45 个组斜率全部为负，B7 的 45 个组斜率也全部为负；B8 的 150 个组斜率全部为正，分位数约为 `1.55–2.50`。B6 的 360 行又与 B7 中同 `experiment_id` 的 360 行逐值相同，说明 B7 是 B6 的严格扩展，而不是另一套独立机制。

## 14. 排除“仅是 `Q` 取了 `1-Q`”的简单解释

对 B8 的 `calibrated` 子集与 B6 做了同一 `(N,D,Q)` 和 `(N,D,1-Q)` 的匹配检查。两种匹配都只得到部分重合，Loss 差异中位数都约为 1.2，且没有形成稳定的一一对应关系。因此 B8 不能被证实为 B6 简单地把质量分数改成 `1-Q`；在没有生成说明前，不能自行做这种转换。
