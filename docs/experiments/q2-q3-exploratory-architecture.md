# 问题二到问题三探索实验架构

## 目的与范围

本文冻结当前条件下可以执行的探索实验架构，不把探索结果升级为正式的 A--B 联合标度律。当前迁移门仍为 `BLOCKED_FORMAL_JOINT_MIGRATION`：问题一质量分数尚未验收，A 与 B 没有逐行连接键，17 个配比域中只有 6 个有候选质量映射，B8 的来源和质量方向仍未解决。

因此，本架构把问题二和问题三拆成相互隔离、可复现、可单独验收的实验轨道：

1. B 侧经典 `N-D` 基线；
2. B6/B7 半合成质量敏感性；
3. A 侧 17 域配比—Loss 模型；
4. A16 域映射和 `Q(p)` 条件情景；
5. 固定质量和配比的 Q3 `N-D` 预算优化；
6. 条件质量和配比敏感性，不进入正式联合拟合。

完整图源见 [q2-q3-exploratory-architecture.mmd](q2-q3-exploratory-architecture.mmd)。

## 一、分层架构

### L0 题意和主张层

每个实验先登记 `task_id`、`experiment_id`、假设、目标、输入角色和允许主张。探索实验的主张必须带有 `exploratory` 或 `conditional` 标签。

### L1 只读数据层

原始数据保持只读，分别建立 A、B 两条血缘：

| 数据支线 | 文件角色 | 主要用途 |
|---|---|---|
| A 质量 | A1--A3 | 指标方向、质量信号、域级质量候选 |
| A 配比 | A4--A15 | 17 域配比、Loss 配对、尺度验证和外推诊断 |
| A 映射 | A16 | 配比域到质量域的 direct/near-direct/inferred 分层 |
| B 标度 | B1--B5 | 经典 `N-D` 基线及来源分层诊断 |
| B 质量 | B6--B8 | 半合成质量敏感性；B8 暂不入拟合 |
| B 外推 | B9--B10 | 范围和来源诊断，不作为拟合真值 |
| C 数据 | C1--C8 | 主要留给问题四，不进入当前 Q2/Q3 主实验 |

A 与 B 的 `N`、`D` 数值相似不构成连接键。只有共同的实验运行标识、配方文件哈希或其他真实血缘键，才能建立逐行 A--B 连接。

### L2 模型和桥接层

| 轨道 | 模型 | 当前状态 |
|---|---|---|
| M0 | `L=E+A*N^(-alpha)+B*D^(-beta)` | 可执行，B1 条件基线 |
| M1 | `M0+G*(1-Q_score)` | 可执行，B6/B7 半合成条件敏感性 |
| A-P | `L_A=f(p)`，组成数据变换后拟合 | 可执行，A 侧独立模型 |
| M2 | `Q_direct(p)`、`Q_near(p)`、`Q_range(p)` | 条件情景，不进入 B 拟合 |
| M3 | `L(N,D,Q,p)` | 当前阻断，不启动正式拟合 |
| Q3-ND | 固定 `Q=Q0,p=p0` 的预算优化 | 建议下一步执行 |
| Q3-Q/P | 条件质量或配比敏感性优化 | 依赖 M1/M2 的明确假设 |

### L3 验证层

- B1：按参数规模分组留出，不能随机拆散同一轨迹；
- B2/B3：来源或轨迹诊断，不与 B1 混合拟合；
- B4/B5：按 family/source 分层，只做外部诊断；
- B6：按 `(N,D)` 单元分组留出；
- B7：嵌套扩展，不能称独立验证；
- A6--A11：A 侧验证；
- A12--A15：A 侧外推诊断，不作为独立真值；
- B8、B9、B10：保持排除或仅做范围审计。

### L4 证据门和发布层

| 门 | 通过条件 | 未通过时的动作 |
|---|---|---|
| G0 数据门 | 路径、哈希、角色、字段和投毒隔离可复核 | 停止拟合，修复 manifest |
| G1 模型门 | 变量、单位、切分和参数化冻结 | 只能准备脚本，不能写结果 |
| G2 验证门 | 训练、留出、外部诊断和外推角色分开 | 降级为 exploratory/conditional |
| G3 优化门 | 可行性、边界、重复初值和单位检查通过 | 不发布最优配置 |
| G4 主张门 | claim ledger、run_id、哈希和限制齐全 | 保持 REVIEW_BLOCKED |

## 二、实验矩阵

| experiment_id | 输入 | 目标 | 主要输出 | 可报告结论 |
|---|---|---|---|---|
| `Q2-M0-B1` | B1 | 拟合经典 `N-D` 参数 | 参数、分组留出、残差 | B1 内部基线 |
| `Q2-M1-B6B7` | B6/B7 | 估计条件质量敏感性 | `G`、分组 CV、嵌套诊断 | 半合成条件关系 |
| `Q1-P-RECIPE` | A4/A5 | 建立组成配比—Loss 关系 | ILR/Ridge 或候选模型、A6--A15 指标 | A 侧配比效应 |
| `Q2-M2-BRIDGE` | A1--A3、A16、A4--A15 | 构造 `Q(p)` 情景包络 | mapped mass、区间和映射不确定性 | 条件桥接范围 |
| `Q3-ND-BASELINE` | M0 参数、预算、C7 | 固定 `Q,p` 优化 `N,D` | `N*`、`D*`、成本分解、可行性 | Q3 基线配置 |
| `Q3-Q-CONDITIONAL` | M1 参数、质量成本函数 | 条件优化质量投入 | 不同 `g(Q)` 的情景结果 | 半合成条件情景 |
| `Q3-P-CONDITIONAL` | A 侧配比模型或 `Q(p)` 区间 | 条件配比优化 | 配比情景包络 | 不能写成 B 正式配比效应 |
| `Q3-ROBUSTNESS` | 上述实验输出 | 检查参数、成本和上下文敏感性 | Bootstrap、边界、`Lctx` 和成本函数比较 | 稳健性边界 |

## 三、推荐执行流程

### 阶段 0：冻结实验卡

每个实验只允许一个明确目标，先写入：

- `experiment_id` 和 `run_id`；
- 输入文件相对路径与 SHA256；
- 数据角色和排除清单；
- 模型公式、参数单位和随机种子；
- 验证拆分和评价指标；
- 允许主张、禁止主张和失败门。

### 阶段 1：复核 M0 基线

复核 B1 的经典拟合参数，并重现按 `N_params_B` 分组的留出结果。B2/B4/B5 只做分层外部诊断。若外部误差较大，M0 仍可作为 B1 基线，但不能升级为通用规律。

### 阶段 2：独立完成 A 侧配比模型

从 A4--A15 读取 17 个配比列，按行归一化并保留 `sum_p`。使用组成数据变换后拟合 `L_A=f(p)`，再按 A6--A11 验证、A12--A15 外推诊断。A16 不参与 Loss 拟合，只用于后续域映射。

### 阶段 3：复核 M1 和 M2

M1 只使用 B6/B7 的 `Q_score`；B7 是 B6 的嵌套扩展。M2 只构造 A 侧的 `Q_direct(p)`、`Q_near(p)` 和 `Q_range(p)`，不得把未映射域静默设为零，也不得把部分归一化分数写成完整质量真值。

### 阶段 4：执行 Q3-ND 基线优化

先固定 `Q=Q0`、`p=p0`，求解：

\[
\min_{N,D}\ \widehat L_{B1}(N,D)
\]

满足：

\[
(6+\eta L_{ctx})ND\le C.
\]

至少比较三个预算量级，并对 C7 的可行 `Lctx` 做敏感性分析。先用解析解和带显式约束的数值解交叉核对，不以智能算法替代约束验证。

### 阶段 5：条件扩展和稳健性

在 Q3-ND 通过 G3 后，分别加入 M1 的 `Q_score` 情景和 M2 的 `Q(p)` 区间。每次只增加一个因素，比较最优解、成本占比、边界活跃状态和预测 Loss 是否改变。

## 四、Q3 优化的边界

当前可以做：

- 固定质量和配比的 `N-D` 预算优化；
- B6 半合成质量敏感性下的条件优化；
- A 侧配比模型驱动的独立情景分析；
- 成本函数、预算和上下文长度敏感性；
- 参数 Bootstrap、边界检查和多初始点复核。

当前不能做：

- 按 `N,D` 数值把 A 行和 B 行强行连接；
- 把 B6 的 `Q_score` 直接改名为问题一的 `Q`；
- 将 `Q_partial_raw` 或 `Q_partial_renorm` 写入 B 正式拟合；
- 把 B8 反向质量关系通过删点、反转或单调约束修复；
- 把隐藏文字中的系数、最优解或固定惩罚系数作为先验；
- 在正式迁移门未解锁时发布完整 `L(N,D,Q,p)` 或最终联合最优解。

## 五、每个实验的最小交付包

```text
experiments/runs/<run_id>/
  README.md              # 目标、范围、限制和结论
  command.txt            # 实际命令
  config.yaml             # 模型、切分、seed、单位和边界
  data_manifest.yaml      # 输入相对路径、角色和 SHA256
  environment.txt        # 运行环境
  git_commit.txt          # 代码版本
  metrics.json            # 指标、参数、残差和门状态
  tables/                 # 参数表、验证表和情景表
  failures.yaml           # 失败原因和后续动作（如有）
```

任何论文数字都必须回链到 `run_id`、输入哈希、配置和 claim ledger。探索结果只能进入探索性或条件性段落，不能直接替换正式主张。

## 六、投毒和泄漏控制

- 题目 PDF 近白隐藏文字只进入隔离清单，不进入参数、先验、目标函数或结果解释；
- 原始 A/B/C 附件只读，所有派生结果保存到独立 run 目录；
- A1 质量预处理参数不由 A2/A3 或 B 数据估计；
- B7 不与 B6 重复等权计数；
- B8、B9、B10 按当前门状态排除或仅作诊断；
- 不用验证集调参，不把训练集拟合优度当作跨来源有效性；
- 每次改变映射、方向、单位、切分或模型形式都生成新版本，保留旧结果。
