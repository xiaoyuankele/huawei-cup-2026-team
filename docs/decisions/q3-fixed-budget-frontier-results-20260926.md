# Q3 固定预算网格前沿结果

运行号：`q3-fixed-budget-frontier-20260926-r01`。

本轮在冻结的 B6 M1 条件模型上，对观测支持域内的 `N-D-Q_score` 建立离散网格，在固定预算、上下文长度、`Q0` 和质量成本族内筛选 Loss—实际成本前沿。

## 运行设置

- `N`：15 个对数网格点，范围为 B1 观测支持域；
- `D`：15 个对数网格点，范围为 B1 观测支持域；
- `Q_score`：19 个线性网格点，范围为 B6 观测支持域 `[0.1,1.0]`；
- `Q0`：`0.1、0.3、0.5`；
- 质量成本：指数、幂函数、对数渐进三类；
- 上下文长度：`2048、4096、8192、32768、131072`；
- 预算：`1e19、1e22、1e24` FLOPs；
- 共 135 个情景，输出 20,257 个非支配网格点。

所有输出均为有限值；本轮没有重新拟合，没有使用 B8，没有使用 Q1 的 `Q_A(p)`，也没有建立 A-B 行级连接。

## 低预算下的质量—规模权衡

以 `C=1e19、Lctx=2048、Q0=0.1` 为例，网格中 Loss 最低的点为：

|质量成本族|`N_B`|`D_B`|`Q_score`|预测 Loss|
|---|---:|---:|---:|---:|
|指数型|0.3058|3.6539|0.70|3.2626|
|幂函数型|0.3058|3.6539|0.60|3.2988|
|对数渐进型|0.6367|1.2140|1.00|3.3485|

这说明低预算下质量成本假设会改变资源分配方向：指数型和幂函数型保留更多 N-D 资源，对数渐进型则倾向于把质量推到高位。

## `Q0` 敏感性

在 `C=1e19、Lctx=2048` 下，最优网格 Q 的变化如下：

|`Q0`|指数型|幂函数型|对数渐进型|
|---:|---:|---:|---:|
|0.1|0.70|0.60|1.00|
|0.3|0.60|0.60|0.90|
|0.5|0.75|0.55|1.00|

结果没有形成稳定的统一 Q 排序，因此报告中应保留 `Q0` 和成本族作为情景条件，不能将某个 Q 值写成普适最优质量。

## 对问题三衔接的意义

1. 固定预算内的前沿比跨预算连续优化更适合展示 N、D、Q 的竞争关系；
2. 低预算时成本族和 `Q0` 的影响与 M1 参数折叠误差同等或更大；
3. 高预算时仍会受到 B1/B6 支持上界限制，超过支持域的配置不能作为验证过的最优；
4. 该前沿仍是 B 侧原生 `Q_score` 的条件结果，不能替代问题一的 `Q_A(p)`，也不能证明 A 侧配比对 B 侧 Loss 的独立作用。
