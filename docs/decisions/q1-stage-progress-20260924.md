### 配比表示与共线性

- 确认 17 个配比变量位于闭合单纯形，直接把全部比例放入含截距线性模型会产生秩亏。

- 生成 A4–A15 的规模特征表，包括总 token 数、`log10_scale` 和域级期望 token 数；生成 16 个 ilr、1 个规模主效应和 16 个交互项的候选输入设计。

### 轨道 A：同尺度配比模型

- 仅用 A4/A5 拟合标准化多输出 Ridge，`alpha` 由 A4 内部五折交叉验证选择为 10。
- A6/A7 作为 1M 同尺度外部验证，平均绝对 R²=0.7649、中心化相对 R²=0.7722、平均 Spearman=0.8898、MAE=0.2626。
- A8–A15 只做拟合后的尺度诊断。A10/A11 绝对 R²=-608.4886，说明 p-only 模型不能跨规模绝对外推。

### 轨道 B：重复配比尺度差异

- A6/A8 的配比矩阵完全相同，1M→60M 时 13 个目标的 Loss 差值全部为正，平均低规模减高规模差值为 1.4594。
- A12/A14 的配比矩阵也完全相同，10B→70B 时平均差值为 0.3829；该组只作为外推敏感性证据。
- 计算了 p-only 跨规模预测误差下界，并用 bootstrap 相关筛查了候选规模—配比交互；没有把差值直接当作回归系数。

### 轨道 C：多尺度角色变更探索

- 明确改变数据角色：A4/A6/A8 作为适配数据，A10 作为未见规模留出，A12/A14 仅作外推诊断。
- 加入 `log10_scale` 和配比—规模交互后，A10 绝对 R² 从 p-only 的约 -608 改善到约 -18.7，说明规模主效应解释了主要跨尺度偏置。
- 低维交互消融显示 top3/top5 交互的 A10 MAE 约 0.591，全量交互 MAE=0.5559、中心化相对 R²=0.0158；但绝对 R²仍为 -18.6736，不能称为可靠外推模型。
- A12/A14 的绝对外推 R² 仍约为 -19 至 -33，因此尚不支持强规模外推结论。

## 2. 当前结论

1. 领域配比对同一规模下的 Loss 排序具有一定稳定性，轨道 A 的 A6/A7 结果支持这一点。
2. 规模是独立且不可忽略的解释变量；同配比跨规模的 Loss 差异证明 p-only 模型不可识别跨规模绝对校准。
3. 规模主效应和交互项可以显著改善探索性跨尺度误差，但当前样本和角色划分不足以证明可靠泛化或外推。
4. 当前不冻结跨尺度最终模型，不把轨道 C 结果写入论文正式结论；正式模型仍以轨道 A 的数据角色和验证边界为准。
