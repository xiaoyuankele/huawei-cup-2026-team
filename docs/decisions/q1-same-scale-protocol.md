# 轨道 A：同尺度配比模型候选协议

本协议只回答 1M 规模下的配比—Loss 关系。A4/A5 是唯一拟合对，A6/A7 是同尺度外部验证；A8–A15 不参与本轨道的绝对模型选择。

当前候选配置为 Helmert-ilr 坐标、乘法零替换 \(\epsilon=10^{-4}\)、线性多响应 Ridge。`alpha` 由 A4/A5 内部五折交叉验证选择。此前的坐标敏感性实验中，该候选的平均 CV R² 为 0.7330，A4 拟合平均 R² 为 0.7535，A6 外部平均 R² 为 0.7649；这些数字是候选协议的探索证据，不是最终模型性能承诺。

正式报告必须保留 13 个目标的逐目标 MAE、RMSE、R² 和 Spearman，而不能只报告均值。还要同时报告 ilr 零替换敏感性、设计条件数、支持距离和 A4/A6 的目标级差异。

该协议仍处于 `CANDIDATE_PROTOCOL_REVIEW`，原因是不同零替换参数会改变 CV 结果。只有在冻结零值语义或接受其敏感性上限后，才能把候选配置升级为正式同尺度模型。
