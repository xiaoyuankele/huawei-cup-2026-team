# 问题一第三问：纯配比、规模修正与可选质量的受控消融

运行号：`q1-mixture-scale-ablation-20260925-r01`。状态：**供论文整理使用的中文草稿，待团队人工复核**。

本实验补足此前质量模型与规模修正之间的连接：以完整的 17 域配比作为主输入，检验同一组规模修正接入纯配比模型后的表现，并把质量评分放在附加特征的消融位置。本次是对已多次查看的数据开展的受控回顾性比较，不是新增的盲测或预注册确认性试验，也不据此宣布跨尺度的单一最优模型。

## 1. 本次证据支持的结论

- 在 A6/A7 的 1M 同尺度评价上，纯配比的二阶 ilr-Ridge 优于线性 ilr-Ridge；合并 RMSE 从 0.3464 降至 0.2840，MAE 从 0.2626 降至 0.2019。这支持将配比非线性作为模型主线。
- 将配对样本估计出的规模修正接入纯配比模型后，A10/A11 的绝对误差大幅下降，但 RMSE 与 MAE 对不同修正的排序不一致，平均逐域 R² 仍为负。改善绝对误差与充分解释逐域变化是不同结论。
- 追加当前版本的 Q_proxy 并未给二阶配比模型带来稳定收益。在 A6/A7 上合并 RMSE 从 0.2840 变为 0.2846；因此本组证据不支持将质量评分设为必要输入。
- 对 A12–A15 的给定估算值，常数规模斜率的长期迁移仍有偏差。10B→70B 的给定平均 Loss 降幅为 0.3829，而 C1 预测为 0.6936；应将这些表用于外推稳健性诊断。

上述结论均来自本次重新计算的输出，没有把历史质量模型的误差移记到纯配比模型名下。

## 3. 模型比较结构

配比满足 $p_i\geq0,\ \sum_{i=1}^{17}p_i=1$。对零值进行乘法替换后，用固定 Helmert 基构造 16 维等距对数比（ilr）坐标 $z(p)$。本次零替换参数固定为 $10^{-4}$，并未重新开展零替换敏感性搜索。

| 基础模型 | 输入表示 | 特征数 | 用途 |
|---|---|---:|---|
| `ilr_ridge` | $z(p)$ | 16 | 纯配比线性基线 |
| `quadratic_ridge` | $z(p)$ 及全部二次项 | 152 | 纯配比非线性候选 |
| `ilr_ridge_qproxy` | $z(p)$ 后追加一个 Q_proxy | 17 | 检验质量表征对线性基线的增量 |
| `quadratic_ridge_qproxy` | 152 个配比特征后追加一个 Q_proxy | 153 | 检验质量表征对非线性模型的增量 |
| `qproxy_only` | 仅 Q_proxy | 1 | 单维质量压缩的辅助参照，不是主基线 |

前四个模型在拟合样本上标准化特征后使用 Ridge，惩罚系数固定为历史设置 10；质量单变量参照使用含截距的普通最小二乘。质量追加在配比特征展开之后，不生成 Q 的平方项或 Q 与配比的交互项。本次二次项是 **ilr 坐标之间的多项式项**，不能逐项直接解释为两个原始领域的因果协同作用。

所有基础模型分别叠加四种相同的规模处理，以便比较基础表示与规模处理的作用：

| 修正 | 定义与拟合来源 |
|---|---|
| C0：无修正 | 保留 A4/A5 学到的基础预测 |
| C1-global：全局修正 | 使用 A6→A8 的配对 Loss 差分在样本、响应上的总均值 |
| C1-domain：逐域修正 | 对每个 Loss 响应分别使用 A6→A8 配对差分均值 |
| C2：配方条件修正 | 以配比预测 A6→A8 的逐域差分；Ridge 惩罚系数固定为历史值 10 |

各修正均采用统一单位：令 $x=\log_{10}(S/1\mathrm{M})$，则

$$
\widehat L_j(p,S)=\widehat f_j(p)+\frac{x}{\log_{10}60}\widehat\Delta_j(p).
$$

其中 C1 的 $\widehat\Delta$ 为常数，C2 为配方条件差分；C0 的差分为零。这样在 60M 时恰好加上拟合的 1M→60M 差分。低尺度配对识别了相同配方下的尺度变化，避免把 A4 与 A10 的总体差异全部归因于配比或规模。

完整特征构造、系数、标准化参数、折分与命令由 [配置](../../configs/q1-mixture-scale-ablation.json)、[计算脚本](../../scripts/q1_s03/mixture_scale_ablation.py) 和 [模型参数](../../experiments/runs/q1-mixture-scale-ablation-20260925-r01/model_parameters.json) 保留，本说明不替代复现文件。

## 4. 结果表与解释

本节的“合并 RMSE”定义为对所有样本、13 个响应的平方误差统一取均值后开方；MAE 是全部样本与响应的平均绝对误差。由于每个响应的样本数相同，后者也等于逐域 MAE 的宏平均。“平均 Loss RMSE”先在每个样本内平均 13 个响应，再计算 RMSE，会受到域间误差抵消的影响，因此仅作补充指标。R² 表示分别对 13 个响应计算后取宏平均。

### 4.1 同尺度：配比信息与非线性主线

表 1. A6/A7，1M，256 个配方，C0 无规模修正。

| 基础模型 | 合并 RMSE | MAE | 平均 Loss RMSE | 平均逐域 R² |
|---|---:|---:|---:|---:|
| 纯配比 ilr-Ridge | 0.3464 | 0.2626 | 0.2495 | 0.7649 |
| 纯配比二阶 ilr-Ridge | 0.2840 | 0.2019 | 0.2211 | 0.8661 |
| ilr-Ridge + Q_proxy | 0.3404 | 0.2574 | 0.2502 | 0.7731 |
| 二阶 ilr-Ridge + Q_proxy | 0.2846 | 0.2022 | 0.2222 | 0.8658 |
| 仅 Q_proxy | 0.7507 | 0.5922 | 0.2856 | 0.0686 |

纯配比二阶模型相对纯配比线性模型的合并 RMSE 下降 18.02%，MAE 下降 23.12%。按配方整行配对重采样得到的误差差值（二阶减线性）分别为 −0.0624，95% 描述性区间 [−0.0834, −0.0420]；以及 −0.0607，区间 [−0.0765, −0.0452]。与单变量质量压缩参照相比，两种完整配比模型都保留了更充分的逐域预测信息。

区间来自 5,000 次配方行配对 bootstrap，每次同时保留该配方的 13 个响应。它们以固定的拟合模型和校准参数为条件，未包含重新训练、参数选择或尺度函数形态的不确定性，且未作多重比较校正；不据此使用未经限定的“统计显著”表述。

表 2. 每格为“合并 RMSE / MAE”；A8 的修正结果为校准内表现，A12/A14 为给定估算值比较。

| 基础模型与评价表 | C0 无修正 | C1-global | C1-domain | C2 配方条件 |
|---|---:|---:|---:|---:|
| ilr-Ridge，A8/A9 | 1.6126 / 1.5188 | 0.5518 / 0.4193 | 0.3734 / 0.2715 | 0.3483 / 0.2627 |
| ilr-Ridge，A10/A11 | 3.0238 / 2.9554 | 0.8077 / 0.5782 | 0.7588 / 0.6446 | 0.7147 / 0.6180 |
| ilr-Ridge，A12/A13 | 3.6096 / 3.5576 | 0.6727 / 0.5192 | 1.0485 / 0.8551 | 1.0428 / 0.8386 |
| ilr-Ridge，A14/A15 | 3.9970 / 3.9402 | 0.6747 / 0.5041 | 1.1909 / 0.9146 | 1.1985 / 0.9289 |
| 二阶 ilr-Ridge，A8/A9 | 1.5993 / 1.5060 | 0.5493 / 0.4109 | 0.3688 / 0.2491 | 0.3017 / 0.2128 |
| 二阶 ilr-Ridge，A10/A11 | 2.6964 / 2.6203 | 0.6575 / 0.4256 | 0.6579 / 0.5469 | 0.6252 / 0.5207 |
| 二阶 ilr-Ridge，A12/A13 | 3.6231 / 3.5551 | 0.7498 / 0.5747 | 1.0923 / 0.9044 | 1.0663 / 0.8609 |
| 二阶 ilr-Ridge，A14/A15 | 4.0107 / 3.9380 | 0.7614 / 0.5671 | 1.2343 / 0.9731 | 1.2199 / 0.9481 |

以 A10/A11 的纯配比二阶模型为例，C1-global 将合并 RMSE 从 2.6964 降至 0.6575（下降 75.61%），MAE 从 2.6203 降至 0.4256（下降 83.76%）；C2 的对应结果为 0.6252 和 0.5207，降幅为 76.81% 和 80.13%。**C2 的合并 RMSE 更低，C1-global 的 MAE 更低**，所以模型选择还需明确希望优先压低较大误差，还是平均绝对误差。当前结果不支持用单一指标宣布某种修正在所有尺度最好。

纯配比二阶模型在 A10/A11 上的平均 Loss RMSE 经 C1-global 和 C2 后分别为 0.2144、0.1782，但相应平均逐域 R² 为 −9.6007、−19.4477。这里负 R² 表示模型在该表上没有达到逐域表内均值参照的平方误差水平，不能因为绝对误差下降就删除该诊断。不同评价表的响应变异范围不同，R² 也不宜脱离表内变异直接横向比较。

为区分 A8 校准内表现与差分拟合的折外表现，还将 256 对配方固定分为五折，每折仅用其余配方拟合修正。纯配比二阶模型的 C1-global、C1-domain、C2 折外合并 RMSE 分别为 0.5493、0.3690、0.3073；C2 的 MAE 为 0.2157。此处 0.3073 与全校准拟合的 0.3017 应分开报告。折外流程限制了每一配方对自身差分修正的直接拟合，但 C2 的惩罚系数源于历史 A6/A8 选择，因此它仍是给定该历史设置的条件性诊断，不是嵌套调参后的独立泛化估计。

### 4.3 可选质量：增量有限且依赖基础表示

本次追加的 Q_proxy 沿用组合表的 v1 版本。它可以由 17 域配比的线性组合重构，最大绝对重构误差为 $1.44\times10^{-15}$。因此 Q_proxy 不是在配方之外观测到的新质量变量；追加它只检验当前特征表示与正则化条件下的预测增量，不能解释为独立的质量因果效应。

在线性 ilr-Ridge 上，A6 的合并 RMSE 下降 0.0061（1.76%），MAE 下降 0.0052；在二阶 ilr-Ridge 上，合并 RMSE 反而增加 0.0006，其描述性 95% 差值区间 [−0.0023, 0.0033] 横跨零。二阶模型接入 C2 后，在 A10 的合并 RMSE 从 0.6252 变为 0.6269，MAE 从 0.5207 变为 0.5241。对 A12/A14，二阶模型加 Q 后的误差变化也很小并随修正和指标改变方向。

这些结果支持在论文中把纯配比模型作为主分析，并将当前 Q_proxy 放入可选消融，而不是用“质量评分必要”概括本组数据。该判断只适用于当前 v1 聚合质量特征，不排除另一种质量定义、样本级质量信息或新的独立数据带来收益。

### 4.4 外推：绝对误差下降不等于高尺度规律已稳定

A12/A14 上，C1-global 对两种纯配比基础模型的合并 RMSE 均低于 C1-domain 和 C2，而在 A8 上排序不同。纯配比二阶模型相对线性模型的同尺度优势，也没有一致延续到这两个估算外推表。辅助参照“仅 Q_proxy + C1-global”在 A14 的合并 RMSE 为 0.5047，比两种纯配比候选更低；这项估算表比较应保留，但不能反过来证明质量压缩适合作为题目主基线。

更直接的迁移检查固定同一配方，比较 10B→70B 的 Loss 变化：给定平均变化为 −0.3829，C1-global 与 C1-domain 均预测 −0.6936，C2 预测 −0.6975。这些差值对基础配比模型相同，因为在固定配方下其基础预测被相减消去。C1 预测的下降幅度比给定值多约 0.3107，显示把 1M→60M 的对数斜率长期外推会高估该区间收益。

仅有低尺度一个配对区间不足以稳定识别尺度曲率、饱和值或分段拐点。本次没有利用 A12–A15 的估算标签反向拟合新的曲率参数，也没有把绝对误差下降解释为真实 10B/70B 性能验证成功。

## 5. 可直接复用的中文论文草稿

**方法段落。** 为建立领域配比与交叉熵损失的定量关系，我们以 17 域配比向量为主要输入、13 个领域的 Loss 为响应，在 A4/A5 的 512 个样本上拟合线性与二阶 ilr-Ridge 模型。通过乘法零替换和等距对数比坐标处理配比的非负性及和为一约束，并固定使用已有实验的正则化设置。质量评分仅作为追加单变量进行消融，另设仅质量评分模型作为辅助参照。为分析规模与配方共同变化的情形，我们用 A6/A7 与 A8/A9 的 256 对相同配方构造 Loss 差分，分别估计全局、逐响应和配方条件三类规模修正，并与无修正模型比较。A6/A7 用于同尺度回顾性评价；A8/A9 同时报告校准内及五折条件性折外误差；A10/A11 用于未参与本次拟合或校准的回顾性评价；A12–A15 仅用于与给定估算值的一致性和外推稳健性检查。主指标为跨样本、跨响应合并的 RMSE 与 MAE，辅以逐域指标、平均 Loss 误差及按配方配对重采样的误差差值区间。

**结果段落。** 在 A6/A7 的同尺度评价中，纯配比二阶 ilr-Ridge 的合并 RMSE 和 MAE 分别为 0.2840、0.2019，相比线性基线下降 18.02% 和 23.12%；仅质量评分参照的对应误差为 0.7507、0.5922。向二阶模型追加当前 Q_proxy 后，两项误差为 0.2846、0.2022，未显示稳定增益。对配方与规模同时变化的 A10/A11，二阶纯配比模型接入全局规模修正后，合并 RMSE 从 2.6964 降至 0.6575，MAE 从 2.6203 降至 0.4256；配方条件修正进一步降低合并 RMSE 至 0.6252，但 MAE 为 0.5207，反映两项误差准则之间的取舍。尽管绝对误差降低，跨尺度的平均逐域 R² 仍为负。在 A12–A15 的估算外推检查中，不同修正的排序发生变化，且低尺度校准斜率预测的 10B→70B 平均 Loss 降幅为 0.6936–0.6975，高于给定估算降幅 0.3829。因此，现有证据支持以完整配比关系为核心、把质量评分作为可选增量，并将规模修正的有效范围限定在本次回顾性评价条件内。

这两段是可复用素材，整合进论文时还需与队伍统一的符号、表号及题目对“规模”的定义对齐；不得把“回顾性评价”“给定估算”删改成“独立盲测”“真实大模型验证”。
