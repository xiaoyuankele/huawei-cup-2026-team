# 问题一配比与尺度可识别性

A6 与 A8 的 17 维配比矩阵完全相同，但分别对应 1M 和 60M；A12 与 A14 的配比矩阵完全相同，但分别对应 10B 和 70B。因此，对任意只依赖配比的确定性预测器 \(\hat y=f(p)\)，同一行配比只能产生一个预测值，不能同时解释两个规模的目标。

若同一配比对应的两个目标为 \(y_a,y_b\)，共享预测值的最小逐行 MAE 为 \(|y_a-y_b|/2\)，最小逐行 RMSE 为 \(|y_a-y_b|/2\)。本次用实际配对差值计算整体下界：

| 重复配比 | 目标均值差 | 共享预测 MAE 下界 | 共享预测 RMSE 下界 | 数据角色 |
|---|---:|---:|---:|---|
| A6/A8（1M/60M） | 1.4594 | 0.7297 | 0.7677 | 外部验证 |
| A12/A14（10B/70B） | 0.3829 | 0.1915 | 0.1944 | 外推敏感性 |

这不是模型调参造成的误差，而是输入变量不包含尺度信息时的识别下界。因而 A8、A14 的绝对 Loss 不能被解释为仅由配比变化引起；p-only 模型跨规模绝对预测应保持 `BLOCKED`。后续若要估计尺度效应，需要先冻结尺度变量、变换方式和可估计的数据角色，并明确哪些规模可参与拟合，哪些只能验证。

脚本：`scripts/q1_scale_identifiability.py`；配置：`configs/q1-scale-identifiability.yaml`。
