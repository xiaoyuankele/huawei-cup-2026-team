# 假设理论 M3：规模、质量与配比的条件联合模型

状态：`THEORETICAL_HYPOTHESIS_NOT_FITTED`

本模型可以用于提出理论假设、设计后续实验和做条件情景分析，但当前不能把参数写成由 A、B 数据正式估计得到的结果。

## 1. 文献依据与组合原则

文献只用于支持模型结构，不用于替代当前数据的参数估计：

- [Kaplan et al., Scaling Laws for Neural Language Models](https://arxiv.org/abs/2001.08361)：支持模型参数量、数据量和算力与 Loss 之间的幂律关系，以及固定算力下的资源分配分析。
- [Hoffmann et al., Training Compute-Optimal Large Language Models](https://arxiv.org/abs/2203.15556)：支持在固定训练算力下联合考虑模型规模和训练 Token 数。
- [Ye et al., Data Mixing Laws](https://arxiv.org/abs/2403.16952)：给出了随数据混合比例变化的指数型函数，并讨论了嵌套使用规模律和混合律的做法。
- [Xie et al., DoReMi](https://arxiv.org/abs/2305.10429)：实验证明预训练域权重会影响模型表现，因此配比 (p) 可以作为影响 Loss 的变量。

不能做的组合是：直接复制这些论文的系数、把不同数据集的 (E,A,B) 平均，或把论文中的质量指标直接等同于本项目的 Q1/B6 分数。

## 2. 推荐的最小理论模型

由于 (p) 是 17 维单纯形变量，先使用零替换后的 ilr 坐标：

```text
z(p) = ilr(p)
z0   = ilr(p0)
```

其中 (p_0) 是基准配比。定义配比对有效数据效率的乘数：

```text
M_p(p) = exp(theta^T [z(p) - z0])
```

提出如下假设 M3：

```text
L_H(N,D,Q,p)
  = E
  + A * N^(-alpha)
  + B * D^(-beta) / M_p(p)^beta
  + G * (1 - Q)
```

等价地，也可以定义：

```text
D_eff = D * M_p(p)
L_H    = E + A*N^(-alpha) + B*D_eff^(-beta) + G*(1-Q)
```

这里的解释是：配比不直接改变模型规模项，而是改变有效数据量；质量项在第一版中与配比项可加分离。这样做的好处是模型参数含义清楚、参数数量少，并且能够退化到已经得到的 M0/M1：

- (p=p_0) 时，(M_p(p)=1)，模型退化为 M1；
- 进一步固定质量项或取 (G=0) 时，退化为 M0；
- (	heta_k<0) 表示沿第 (k) 个 ilr 配比方向提高数据效率，(	heta_k>0) 表示降低数据效率。

## 3. 可选的交互扩展

只有在有共同 A-B 批次键、且样本量足够时，才增加质量—配比交互：

```text
L_H+ = L_H + H * (1-Q) * D^(-beta) / M_p(p)^beta
```

其中 (H) 检验“质量提升在不同配比下是否有不同收益”。当前不建议直接使用这一扩展，因为 (H)、(	heta) 和 Q 的尺度变换会严重混淆。

## 4. 可检验的理论命题

该模型不是只给一条公式，还给出可验证的命题：

1. **规模律命题**：固定 (p,Q) 时，(N,D) 的边际收益服从幂律衰减；这对应现有 M0/M1。
2. **配比效率命题**：固定 (N,D,Q) 时，配比改变只通过 (M_p(p)) 改变有效数据效率。
3. **质量收益命题**：固定 (N,D,p) 时，(Q) 的边际收益由 (G) 控制。
4. **可加性命题**：第一版假设质量效应与配比效应没有交互，即交互项 (H=0)。
5. **资源替代命题**：在等 Loss 曲线上，增加 (Q) 或改善 (p) 可以减少所需的 (D)，但替代率随 (D) 增大而变化。

例如，质量与数据的局部替代率可以定义为：

```text
dD/dQ |_L = - (partial L / partial Q) / (partial L / partial D)
```

问题三中更实际的识别量是成本调整后的边际收益：

```text
R_Q = -(partial L / partial Q) / (partial C / partial Q)
R_D = -(partial L / partial D) / (partial C / partial D)
```

当 (R_Q=R_D) 时，定义为质量投入和数据投入的结构性转移点。上下文长度还会通过

```text
Lctx_crit = 6 / eta = 30000
```

改变训练开销与注意力开销的相对权重。C7 的 8192 和 32768 正好位于这个临界值两侧。

## 5. 当前如何使用

当前只能做三类使用：

- **理论说明**：解释为什么配比可以进入有效数据量，而不是直接与 B1 Loss 相加；
- **条件敏感性**：给定 (h(Q_A))、(G)、(	heta) 的假设范围，输出 (N^*,D^*) 的区间；
- **实验设计**：要求未来收集共同批次键，并在不同 (p,N,D,Q) 组合上估计参数。

当前不能做的事情：

- 不能把 (G)、(	heta) 或 (H) 写成已经由现有 A、B 数据拟合出的参数；
- 不能把 Q1 的 `0–100` 直接代入模型中的 (Q)；
- 不能把文献中其他数据集的参数迁移到本项目；
- 不能由该理论模型声称得到跨 A-B 的真实最优配比。

## 6. 正式拟合所需的最小数据

要把 (L_H) 从假设模型升级为可估计模型，至少需要每条记录同时包含：

```text
(batch_id, p, N, D, Q, Loss, Lctx, training_protocol)
```

并且需要：

1. Q 的共同量纲或一组可审计的配对校准样本；
2. 至少多个批次和多个 (N,D) 水平，避免 (	heta) 与 (B) 混淆；
3. 留出批次验证，而不是只做随机行切分；
4. 对 (H=0) 与 (H\ne0) 做嵌套模型比较；
5. 对 inferred 域和 B8 保持单独敏感性，不得静默并入主拟合。

因此，M3 不是没有理论路径，而是目前只能作为“文献支持的可检验假设模型”。
