## 3. 配比相对效应指标

对每个数据集的每个 Loss 目标先去除该数据集目标均值，再评价配比变化能否保持排序和相对形状。它不评价绝对 Loss 偏置，因此不能替代绝对预测指标。

| 数据对 | 中心化相对 R² | 平均 Spearman |
|---|---:|---:|
| A4/A5 | 0.8016 | 0.9159 |
| A6/A7 | 0.7248 | 0.8671 |
| A8/A9 | 0.6078 | 0.8723 |
| A10/A11 | -7.4018 | 0.8363 |
| A12/A13 | -3.7033 | 0.4714 |
| A14/A15 | -6.5616 | 0.3848 |

A8/A9 的 Spearman 较高而绝对 R² 很差，说明主要问题是规模偏置；A10/A11 即使排序相关性仍有 0.8363，中心化 R² 仍很差，说明其幅度关系也不稳定。

## 4. 数据设计和支持指标

- A6 与 A8 的配比矩阵完全相同，但平均 Loss 为 5.2823 和 3.8229，平均差 1.4594。
- A12 与 A14 的配比矩阵完全相同，但平均估算 Loss 为 1.7975 和 1.4145，平均差 0.3829。
- A4 设计矩阵含截距时秩为 17，条件数约 209.11；线性基线已删除一个参考域。
- 相对 A4 的逐列范围检查：A6/A8 有 2.7344% 配方越界，A10 有 6.25% 越界。
- A10 最近 A4 配方的标准化距离最大约 16.6256；A12/A14 是 A4 子集。

## 5. 当前能支持的结论

目前只能说：配比对同一尺度内的 Loss 变化具有可测的预测信号；跨尺度时，配比排序部分保留，但绝对 Loss 受到明显规模效应影响。当前指标不能支持“跨尺度共用一组系数”、绝对最优配方或质量评分 (Q) 的独立贡献。
