# 轨道 C 特征块消融结果

运行号：`q1-track-c-ablation-20260924-r01`。A4/A5、A6/A7、A8/A9 用作适配数据，A10/A11 作为未见规模留出；因此结果属于角色变更探索。

| 特征块 | 预测变量数 | A10 绝对 R² | A10 中心化相对 R² | A10 MAE |
|---|---:|---:|---:|---:|

消融结果说明：

- 加入规模主效应后，A10 绝对误差从仅 ilr 的严重失败显著降低，规模变量确实解释了主要跨尺度偏置；
- 加入交互项后，A10 的中心化相对 R² 从负值恢复到接近 0，说明配比排序得到一些恢复，但绝对 (R^2) 没有优于“ilr + 规模主效应”；
- 交互项的价值主要体现在相对结构，而不是当前数据下的绝对校准；
- 这些结果不能作为官方外部验证，因为 A6/A7 和 A8/A9 已被用于适配。

当前不应继续无约束增加交互项。后续若重新设计多尺度拟合，应优先比较低维交互、目标分层和规模区间分段模型。
