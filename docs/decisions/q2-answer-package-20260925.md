# 问题二条件性答案包

当前问题二采用条件迁移路线。由于 A、B 没有唯一 ID，不能识别样本级的 `p` 或 Q 对 B 侧 Loss 的独立效应，因此答案不构造正式的 `L(N,D,Q,p)` 联合模型。

## 主标度律

B1 使用

\[
L(N,D)=E+A N^{-\alpha}+B D^{-\beta}
\]

得到参数 `E=1.68980`、`A=0.35398`、`B=1.24031`、`alpha=0.33998`、`beta=0.27988`。按参数规模分组的 8 折留出内部 (R^2) 为 `0.9999992--0.9999998`。B2、B4、B5 保留为外部诊断，不能合并为跨来源普适定律。

## 质量敏感性

B6/B7 单独使用其原生 `Q_score`：

\[
L=E+A N^{-\alpha}+B D^{-\beta}+G(1-Q_{score}).
\]

B6 的 5 折 N-D 单元留出 (R^2) 为 `0.9526--0.9705`，(G=0.36225)。在该半合成模型内部，`Q_score` 从 `0.1` 增至 `1.0` 对应的预测 Loss 变化为 `-0.3260`，B6 行的相对下降均值约 `11.88%`，5%--95% 分位约为 `9.63%--13.89%`。这些是模型内条件响应，不是 Q1 质量迁移结果，也不是因果效应。

## 弹性

弹性按

\[
\varepsilon_x=\frac{\partial L}{\partial x}\frac{x}{L}
\]

计算。B1 的平均 (ε_N) 为 `-0.05389`，平均 (ε_D) 为 `-0.04155`。B6 的平均 (ε_N) 为 `-0.05991`，平均 (ε_D) 为 `-0.04095`，平均原生 `Q_score` 弹性为 `-0.07751`。替代比 `dlnN/dlnQ_score` 和 `dlnD/dlnQ_score` 只在 M1 半合成模型内部使用。

## Q1-derived Q/p 与 B8

Q1-derived Q/p 已完成 1214 行接口预检和 5 个场景敏感性分支，但只作为 A 侧条件场景变量；它没有与 B Loss 逐行连接，也没有转成 B6/B7 的 `Q_score`。B8 已完成来源和方向审计，因来源不完整、质量语义未定义且与 B6/B7 存在系统方向冲突，排除出主拟合并保留排除证据。

这套结果可以回答问题二的规模律、分层验证、条件质量敏感性、弹性和外推边界；不能支持已验证的 17 域质量映射、A-B 样本级质量效应或正式联合标度律。
