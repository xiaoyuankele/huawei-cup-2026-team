# 轨道 C 多尺度探索实验

运行号：`q1-track-c-multiscale-exploratory-20260924-r01`。

本实验明确改变数据角色：A4/A5、A6/A7、A8/A9 作为适配数据，A10/A11（1B）作为未见规模留出；A12–A15 只做外推诊断。因此该结果不能替代严格轨道 A 的官方验证。

相较于只用配比的轨道 A，显式加入规模和交互项后，A10 的绝对 R² 从约 -608 改善到约 -18.7，说明规模变量确实解释了大部分跨尺度偏置；但 A10 仍未达到可接受的绝对预测水平，10B/70B 也仍然较弱。因此规模条件模型方向正确，但当前数据仍不足以支持强外推结论。

该运行的最大限制是它使用了 A6/A7 和 A8/A9 作为适配数据，所以这些数据不再是官方外部验证。运行状态为 `ROLE_CHANGE_EXPLORATORY`，不进入论文正式结果。
