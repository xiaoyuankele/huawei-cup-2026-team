# 问题二四量条件模型预检

本轮把题目要求的四个量 (N,D,Q,p) 放入同一个条件接口，但没有把不可识别的量伪装成已拟合系数。

候选形式为：

\[
L_{\mathrm{cond}}(N,D,Q_A(p))
=E+A N^{-\alpha}+B D^{-\beta}
+G_{\mathrm{bridge}}\left[1-Q_A(p)\right],
\]

其中

\[
Q_A(p)=\sum_{j=1}^{17}p_jq_j.
\]

预检结果：17 个 p 列的和误差为 `1.55e-15`，Q 有限且在 0--100，Q/p 接口共 1214 行。B1 提供 N、D 的主基线，Q1-derived Q(p) 可在 A 侧计算，B6/B7 只提供原生 `Q_score`。

`G_bridge` 目前不可识别，因为 A、B 没有行级或批次级唯一桥接键；配比 p 对 B Loss 的独立系数同样不可识别。因此该形式是四量条件模型规格和场景接口，不是正式拟合定律。B8 继续排除，Q1 的 Q 不转换为 B6/B7 的 `Q_score`。

这满足“考虑四个量”的题目要求，同时明确了当前数据能够支持的边界：N、D 可在 B1 上估计，Q(p) 和 p 可做 A 侧条件敏感性，跨 A-B 的 Q/p 效应只能作为未识别项保留。
