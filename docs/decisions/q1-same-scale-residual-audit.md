A6 的 13 个目标平均残差均为负，范围约为 -0.1072 至 -0.0278，说明候选模型在该外部验证集上存在一致的轻微高估（\(y-\hat y<0\)）。这属于同尺度校准偏差，不能用 R² 单独看出。正式报告应同时保留残差均值和误差尺度，并检查这种偏差是否在不同零替换设置下稳定。

该结果不改变跨规模结论：A8 的绝对 Loss 仍受规模偏置支配，不能用 A6 的校准偏差直接修正。
