# 问题一有限扰动效应稳定性结果

运行号：`q1-effect-stability-20260924-r01`。本运行使用模型基准实验中选出的 ilr-Ridge 和二阶 Ridge，在 A4 逐列边际范围内进行配比质量转移：从源领域向目标领域转移 `delta=0.01`，并对每个目标 Loss 使用 300 次行 bootstrap 计算平均效应区间。

| 数据 | Ridge 与二阶 Ridge 效应方向一致率（跨目标平均） |
|---|---:|
| A4/A5 | 0.714 |
| A6/A7 | 0.690 |

二阶 Ridge 的预测性能优于线性 Ridge，但两个模型的有限扰动方向仅在约 69%–71% 的领域对上保持一致。由此得到的解释边界是：二阶模型可以作为预测候选，但其单个组合项尚未达到稳定机制解释标准。有限扰动是模型预测效应，不是因果干预；A4 边际范围筛查也不等价于凸包支持判定。

下一步应优先进行交互项稳定性筛选和坐标/零替换敏感性分析，不应直接根据二阶系数对领域组合排序。
