# 轨道 C 低维规模—配比交互结果

运行号：`q1-track-c-reduced-interactions-20260924-r01`。A4/A5、A6/A7、A8/A9 用作适配数据，A10/A11 作为未见规模留出，A12/A13 与 A14/A15 只作外推诊断。因此本结果属于角色变更探索，不能替代题目官方验证。

本实验固定规模主效应，并比较保留 1、3、5 个轨道 B 在 A6/A8 重复配比筛出的 ilr 交互与全量 16 个交互。候选顺序为 `ilr_12, ilr_5, ilr_3, ilr_16, ilr_6`。这些坐标来自已有差值筛查，只用于提出低维假设，不构成确认性特征选择。

结果表在 `experiments/runs/q1-track-c-reduced-interactions-20260924-r01/reduced_interaction_metrics.csv`，每个特征块的 alpha 选择记录在 `selected_alpha_logo.csv`。判定重点是 A10 的绝对 R²、中心化相对 R² 和 MAE 是否同时改善；若只改善相对结构而绝对误差不降，则仍不能视为可外推模型。

A10/A11 留出结果如下：

| 特征块 | 变量数 | 绝对 R² | 中心化相对 R² | MAE |
|---|---:|---:|---:|---:|
| ilr + 规模 | 17 | -17.9459 | -1.6725 | 0.6182 |
| 规模 + top1 交互 | 18 | -17.8317 | -1.6953 | 0.6123 |
| 规模 + top3 交互 | 20 | -17.2007 | -1.3363 | 0.5912 |
| 规模 + top5 交互 | 22 | -17.2275 | -1.3074 | 0.5915 |
| 全量 16 交互 | 33 | -18.6736 | 0.0158 | 0.5559 |

低维交互在 A10 上确实降低了 MAE，并使绝对 R²略有改善，但中心化相对 R²仍为负；全量交互的相对结构最好，代价是变量数更高且绝对 R²没有同步改善。因此当前证据不支持把 top1/3/5 直接冻结为最终模型，只支持“规模主效应必须进入候选、低维交互可作为正则化候选”的判断。

A12/A13、A14/A15 的外推诊断中，top3/top5 相对 ilr+规模略有改善，但绝对 R²仍约为 -19 至 -33，未形成可靠外推。全量交互的中心化相对 R²在两个诊断集上更好，但这不能抵消其外推角色限制。

限制：A10 被作为未见规模留出，但适配数据包含 A6/A7 和 A8/A9；因此本运行只能评价“多尺度适配协议下的探索表现”，不能作为最终泛化能力证明。正式模型仍须保持轨道 A 的官方验证边界，或重新设计独立的多尺度训练—验证划分。
