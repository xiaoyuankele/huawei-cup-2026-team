# 问题一第三小问：尺度迁移量转移结果

运行号：`q1-scale-shift-transfer-20260925-r01`。A6/A8 和 A12/A14 的配方矩阵逐行完全相同，因此可以直接比较相同配方在不同规模下的 Loss 差值。实验用 A6/A8 的 1M→60M 目标级平均下降量，按对数规模间隔比例转移到 A12/A14 的 10B→70B 区间。

两组规模间隔分别为 1.778 和 0.845 个十进制数量级，转移比例为 0.475。A6/A8 的平均目标下降量为 1.459，转移后预测 A12/A14 的平均下降量为 0.694，而实际 A12/A14 的平均下降量只有 0.383。

| 指标 | 数值 |
|---|---:|
| 实际 10B→70B 平均 Loss 下降 | 0.3829 |
| 由 1M→60M 转移得到的平均下降 | 0.6936 |
| 转移预测 MAE | 0.3107 |
| 实际下降量平均绝对值 | 0.3829 |

逐目标结果显示，13 个目标的转移量全部高估了 10B→70B 的实际下降量；github、arxiv 和 pubmed_central 等目标的误差尤其明显。由此可见，规模效应不能用一个跨区间稳定的对数线性下降规律表示。

该结果还解释了为什么质量分迁移只能改善局部验证：对于 A6/A8 与 A12/A14 这种相同配方的成对数据，质量分、配比和多样性特征完全相同，只有规模改变，因此质量分无法解释这部分成对尺度偏移。

实验状态为 `PAIRED_SCALE_DIAGNOSTIC`。完整逐目标和逐行结果见 `experiments/runs/q1-scale-shift-transfer-20260925-r01/`；脚本和配置分别见 `scripts/q1_scale_shift_transfer.py` 与 `configs/q1-scale-shift-transfer.yaml`。
