# 问题一第三小问：可执行分析轨道拆分

当前数据角色不允许把 A6–A15 的目标直接并入 A4/A5 拟合。因此后续实验拆成三条互不混淆的轨道。

## 轨道 A：同尺度配比—Loss 关系

目标是回答“在 1M 规模下，配比变化与 13 个 Loss 目标的相对关系如何”。

- 拟合：A4/A5；
- 外部验证：A6/A7（同为 1M）；
- 输入表示：预先冻结的 Helmert-ilr 或参考域对比；
- 模型：线性 Ridge 为主，二次项只作为 A4 内部敏感性；
- 报告：逐目标 MAE、RMSE、R²、Spearman、条件数、VIF/ilr 敏感性和支持距离；
- 结论上限：同尺度配比关联和有限的外部验证，不能写成跨规模规律或因果域效应。

## 轨道 B：重复配比的尺度差异

目标是回答“相同配比从一个规模变到另一个规模时，Loss 发生了多大变化”。

- A6/A8：1M 对 60M，属于外部验证中的重复设计；
- A12/A14：10B 对 70B，属于外推敏感性；
- 统计对象：逐行、逐目标的配对差值 \(D_{a,b}=Y_a-Y_b\)；
- 不拟合配比系数，不把差值当作 A4 的残差修正；
- 报告：均值差、绝对差、目标间差异范围和共享 p-only 预测误差下界。

这条轨道能证明 p-only 模型缺少规模信息，但不能估计一个可推广的规模斜率。

## 轨道 C：规模条件模型的未来方案

候选形式为

\[
Y_{s,k}=\beta_{0k}+f_k(z(p))+\gamma_k\log_{10}s+h_k(z(p),\log_{10}s)+\varepsilon_{s,k}.
\]

候选中的规模主效应和交互项在合并输入设计上可以达到满秩，但 A4/A5 只有一个规模，因此当前拟合角色无法估计 \(\gamma_k\) 和 \(h_k\)。只有在重新冻结数据角色、明确哪些规模目标可参与拟合、并设计独立留出规模后，轨道 C 才能执行。

## 当前执行顺序

1. 先冻结轨道 A 的坐标基、零处理、正则化和报告指标；
2. 用轨道 B 描述规模差异和 p-only 识别下界；
3. 轨道 C 暂存为设计方案，不把输入秩审计误写成已拟合的规模模型；
4. 三条轨道的结果分别进入 claim ledger，不共享未经声明的系数或 R²。

该拆分保持 A4/A5 拟合、A6–A11 验证、A12–A15 外推的原始角色不变。
