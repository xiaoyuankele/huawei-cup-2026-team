# 问题二到问题三的衔接实验方案架构

## 1. 目标与边界

目标是把问题二得到的规模律、质量敏感性和问题一得到的配比/域质量信息，组织成问题三可以复核的优化输入。

当前 A、B 数据没有样本级或批次级唯一桥接键，因此本方案采用条件情景衔接：

- `N,D` 在 B1 上估计主规模律，并进入问题三的资源分配优化；
- B6/B7 的原生 `Q_score` 作为 B 侧质量条件变量，单独进入质量—资源竞争实验；
- 问题一的 `p` 和 `Q_A(p)` 作为 A 侧离散策略/情景变量，与问题三的 `N,D` 场景并列报告；
- 在获得合法桥接键、共同质量标度和可审计来源之前，不把 `Q_A(p)` 转成 B6/B7 的 `Q_score`，也不拟合声称识别了 `L(N,D,Q,p)` 的跨来源联合系数。

## 4. 四量接口的正确使用方式

问题一侧先计算

\[
Q_A(p)=\sum_{j=1}^{17}p_jq_j,\qquad p_j\ge 0,\quad \sum_jp_j=1.
\]

然后把它放在条件情景中：

\[
L_{\mathrm{cond}}(N,D,Q_A(p))
=E+A N^{-\alpha}+B D^{-\beta}
+G_{\mathrm{bridge}}[1-Q_A(p)].
\]

这个式子目前是接口规格，不是已识别模型，因为 `G_bridge` 需要 A-B 的共同样本或批次键才能估计。当前执行时应拆成三条可识别路径：

1. **N-D主路径**：用 M0 估计 `N,D` 对 B1 Loss 的响应，供 Q3 做基线优化。
2. **B侧质量路径**：用 M1 的原生 `Q_score` 做 Q 与 N、D 的预算竞争实验。
3. **A侧配比路径**：用 `p` 和 `Q_A(p)` 生成离散策略情景，与 Q3 的 N-D 结果形成面板；不把 A 侧 Loss 和 B1 Loss 相加。

## 5. 问题三的优化目标

### 5.1 N-D 基线

\[
\min_{N,D}\;\widehat L_{M0}(N,D)
\quad\text{s.t.}\quad C_{ND}(N,D,L_{ctx})\le C,
\quad (N,D)\in\mathcal S_{B1}.
\]

若解析解落在 B1 支持域之外，必须同时输出支持域约束解，并把无约束解标为外推，不能称为已验证最优。

### 5.2 B侧质量条件优化

\[
\min_{N,D,Q_{score}}\;\widehat L_{M1}(N,D,Q_{score})
\quad\text{s.t.}\quad C_{ND}+C_Q(Q_{score},D)\le C,
\quad Q_{score}\in[0.1,1.0].
\]

指数、幂函数和对数型质量成本都要保留，报告低预算下的分歧，不能只保留把 Q 推到上界的单一情景。

### 5.3 A侧配比条件情景

对观测过的候选 `p` 逐个建立 Q3 面板：

\[
\{(p^{(k)},Q_A(p^{(k)}),N^*,D^*,\widehat L_{M0},\text{cost})\}_k.
\]

它回答“某个已观测配比在不同资源配置下如何比较”，不回答“跨 A-B 的最优配比是什么”。

## 6. 衔接所需的验证和敏感性实验

1. **参数不确定性传播**：对 M0/M1 的折叠参数逐折重算 Q3 最优解，输出 N、D、Q、Loss 和成本的区间，而不是只给点估计。
2. **支持域约束敏感性**：分别报告严格支持域、适度外扩和无约束解析解，并标记外推比例。
3. **质量成本敏感性**：保留指数、幂函数、对数三类成本；同时改变 `Q0`，观察最优 Q 是否稳定。
4. **配比情景敏感性**：比较观测候选、c4单分支和已审核分支集合；p 始终作为离散策略标签。
5. **映射敏感性**：对 11 个 inferred 域使用候选先验或剔除后重算 `Q_A(p)`；只报告排序和区间变化，不把敏感性结果写成真实标签。
6. **伪桥接对照**：显式运行“按行号连接”或“强行尺度转换”的负面对照，只用于证明会产生什么偏差，不能进入主结果。

## 7. 当前状态与下一步

当前可以直接使用的结果是：M0 B1 N-D 基线、M1 B6/B7 原生质量条件、Q1-derived p/Q 情景接口、Q3 N-D/Q/p 三类探索包。当前不能做的是正式的 A-B 样本级联合拟合；原因是没有唯一桥接键，Q1 的质量量纲也没有被验证为 B6/B7 的 `Q_score`，B8 的来源和方向审计仍不满足主拟合要求。

下一轮按以下顺序执行：

1. 以 M0/M1 的折叠参数运行 Q3 不确定性传播；
2. 汇总严格支持域下的 Pareto 前沿，并列出外推解；
3. 将三类 Q 成本和 Q0、p 映射分支合并为稳健性矩阵；
4. 形成“已验证基线—条件情景—未识别联合项”的最终答案表；
5. 只有出现合法 A-B 桥接键、共同 Q 标度和独立验证证据，才开启正式四量联合拟合。

## 8. 结论分层

- **可以回答**：B1 的 N-D 标度关系、B6/B7 原生质量条件、Q3 的资源分配情景、离散 p 情景比较、外推和成本假设的影响。
- **可以作为条件结果**：将 `Q_A(p)` 与 N-D 资源配置并列形成四量条件面板。
- **目前不能回答**：A 侧质量/配比对 B 侧 Loss 的样本级独立效应、Q1 Q 与 B6/B7 `Q_score` 的数值等价、正式的 `L(N,D,Q,p)` 跨来源联合标度律。
