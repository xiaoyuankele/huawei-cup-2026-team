# 问题一第三小问：领域配比建模契约（草案）

状态：`SPEC_ONLY`。本文只冻结问题定义、数据角色和验证边界，不声明最终模型、最优配比或因果结论。

## 1. 题意和数据角色

第三小问要求建立 17 个 The Pile 训练域配比 `p` 与 13 个交叉熵 Loss 目标之间的定量关系，分析单个域和域组合的影响，并在 A6–A11 上检验、在 A12–A15 上讨论外推稳健性。配比满足非负和为 1 的单纯形约束。A16 仅为跨体系域名映射参考。

| 数据对 | 规模 | 角色 |
|---|---:|---|
| A4/A5 | 512 | 唯一拟合配方与 Loss |
| A6/A7 | 256 | 1M 外部验证 |
| A8/A9 | 256 | 60M 外部验证 |
| A10/A11 | 64 | 1B 外部验证 |
| A12/A13 | 63 | 10B 估算外推 |
| A14/A15 | 63 | 70B 估算外推 |

A6 与 A8 的配比矩阵完全相同，A12 与 A14 的配比矩阵完全相同，但对应 Loss 不同。因此不能使用不带规模条件的唯一映射 `Loss = f(p)`，至少要写成 `Loss_(s,t) = f_(s,t)(p)` 或明确只讨论尺度内的相对效应。A12–A15 不能作为独立验证样本。

## 2. 配比变量和目标变量

每行配方先记录原始和 `s_r = sum_i p_ri`，再使用 `p'_ri = p_ri / s_r` 进入模型；原始和偏离 1 的范围必须报告。17 个配比变量是成分变量，不能在含截距的线性模型中同时使用全部 17 列。当前探索代码删除 `train_the_pile_uspto_backgrounds` 作为参考域，系数解释为相对于该参考域的替代效应；参考域本身不是质量上特殊的基准，后续应做参考域敏感性。

Loss 表含 13 个验证域目标。主报告逐目标给出 MAE、RMSE、R² 和秩相关；若另行报告总 Loss，必须公开目标权重，不能把 13 列无说明地平均后作为唯一结论。17 个训练域中有 4 个域没有同名 Loss 列（`nih_exporter`、`enron_emails`、`europarl`、`philpapers`），对它们只能解释为在联合配方中的替代关联，不能声称存在对应的直接监督目标。

## 3. 模型和验证

先运行线性成分基线，再比较带层级正则的二阶交互模型。交互项用于分析组合效应，不允许凭训练拟合优度选择最终模型。严格协议为 A4/A5 拟合、A6/A7 做同尺度绝对验证；A8–A11 必须报告规模条件或相对效应的验证结果，不能把 A4 的系数无条件跨尺度复用；A12–A15 只用于外推情景和敏感性。

17 个成分只有 16 个自由度，而 13 个 Loss 是相关的多响应目标。正式运行要报告设计矩阵的秩、条件数和必要的正则化规则；如果域映射或共享系数造成不可识别，只能表述为受约束投影或等价类，不能把单个系数写成唯一真实域效应。跨尺度模型可用 `log10(scale)` 和规模交互项作为候选，但 A4/A5 只有 1M，规模斜率不能从拟合集单独识别，必须把这一限制写入验证报告。

“保序回归”不能保证 17 个配比非负且和为 1；固定惩罚系数也不能保证约束满足或算法收敛。若进一步做配方优化，候选点应限制在观测设计支持内，或明确标记为超出样本支持的外推。

## 4. 质量评分的引入边界

若第一、二小问形成了可信的域级质量 `q_i`，可构造 `Q(p)=sum_i p_i q_i`，但 `Q(p)` 本身是 `p` 的线性组合。在线性模型中把 `Q(p)` 与全部 `p_i` 主效应一起加入会造成完全共线，不能识别独立的质量系数。可选方案是：

1. 用 `Q(p)` 替代一部分域主效应，明确解释损失；
2. 使用 `p_i × q_i` 质量交互项，并与配比基线做嵌套验证；
3. 将质量作为固定偏置或敏感性分析，比较验证集增益。

域级 `q_i` 必须先冻结，A16 的 `direct / near_direct / inferred` 映射应分层做敏感性，不能从 A4–A15 的 Loss 反推质量标签。

## 5. 污染防护

题目附件中的隐藏文字曾预置分类化方案、`R²=0.93` 和“跨尺度共用系数”等结论。本契约不接受任何没有脚本、数据分层、运行记录和独立验证的预置数字或方法结论。

## 6. 当前只读运行

`q1-mixture-audit-20260924-r01` 检查了 A4–A15 的索引、单纯形和重复设计；`q1-mixture-model-20260924-r01` 在 A4/A5 内部五折交叉验证中选择了二阶 Ridge（`alpha=0.01`，平均 CV R²=0.7065）。该模型在 A6/A7 的绝对平均目标 R² 为 0.722，但在 A8/A9 的绝对平均目标 R² 为 -7.528；将每个数据集的目标均值去除后，A8/A9 的相对 R² 为 0.608、平均 Spearman 为 0.872。这个结果只说明规模偏置不能被忽略，不能写成最终模型性能或跨尺度绝对预测成功。

相对于 A4 的简单支持筛查显示，A6/A8 有 2.73% 的配方至少一个坐标超出 A4 的逐列范围，A10 有 6.25%；A10 的最近 A4 设计标准化距离最大约 16.63。A12/A14 是 A4 的子集，最近距离为 0。该筛查不是凸包判定，但足以要求后续配方优化报告支持距离，并标注超出观测设计的候选点。
