# 问题二条件迁移桥接决策

用户已确认：A、B 没有唯一 ID 将样本链接在一起。

因此，当前数据不支持样本级的 A-B 联合拟合，也不能从现有文件中识别配比 `p` 对 B 侧 Loss 的独立效应。仅有相同的规模、参数量或 token 数，不能替代共同实验 ID，因为这些字段可能来自不同数据生成过程和不同实验来源。

从本轮开始，桥接状态冻结为 `conditional-no-row-key-v1`：

- A 侧继续使用 Q1-derived `Q/p` 做域级和场景级敏感性分析；
- B1、B3、B4/B5 按各自数据角色独立报告；
- B6/B7 只分析其原生半合成 `Q_score`，不改名为 Q1 的 Q；
- B8 在来源和质量方向未解决前排除出主模型；
- 不再尝试按行号、scale 或仅按 `N,D` 进行 A-B 拼接。

这不是实验失败，而是对可识别性的正式限定。只有未来出现外部实验记录、批次级聚合对应关系或其他可追溯桥接证据，才重新开启 A-B 联合模型预检。
