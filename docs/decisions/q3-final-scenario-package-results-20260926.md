# 问题三最终条件情景包

运行号：`q3-final-scenario-package-20260926-r01`。

本包把问题二的 M0/M1 参数传播、固定预算 `N-D-Q_score` 网格前沿和问题一的 6 个配比候选整理成可写入报告的条件情景表。

## 输出内容

- 135 行 `q3_conditional_recommendation_scenarios.csv`：每个 `Q0—成本族—上下文—预算` 情景的支持域内最低 Loss 网格候选；
- 9 行 `q3_representative_scenarios.csv`：`Lctx=8192、Q0=0.1` 下三档预算和三类成本族的代表情景；
- 6 行 `q1_p_candidate_claim_bounded_ranking.csv`：A 侧配比候选的观测/预测排序；
- 7 行 `q3_claim_ledger.csv`：问题三可主张、条件主张和不可识别结论的边界。

## 代表情景解释

在 `Lctx=8192、Q0=0.1` 下：

- 低预算时，指数型、幂函数型和对数渐进型成本给出的 Q 与 N-D 配置明显不同，应并列报告；
- 中预算时，网格最优 Q 通常到达 1.0，但这一结果仍依赖 M1 参数和质量成本函数；
- 高预算时，N、D 已碰到 B1 支持边界，结果不能称为验证过的全局最优。

## 配比候选的报告方式

A 侧预测排名第一的是候选 46，A 侧观测 Loss 最低的是候选 170。二者排序不一致，因此不能给出稳定的跨来源“最优配比”。最终表中只把它们作为离散策略候选，同时保留 `Q_A(p)` 和 B 侧 `Q_score` 的不同定义。

## 结论分层

|结论|状态|
|---|---|
|M0 可用于条件 N-D 资源分配|条件支持|
|M1 可用于 B6 原生 Q_score 成本敏感性|条件支持|
|最优 Q 依赖 Q0、预算和成本族|条件支持|
|A 侧 p 可与 B 侧前沿形成条件情景面板|情景支持|
|A 侧 p 或 Q_A(p) 的 B 侧独立系数已被识别|不可识别|
|Q1 Q_A(p) 与 B6 Q_score 等价|尚未建立|
|跨来源四量全局最优已验证|阻断|

该包没有新增 A-B 连接，也没有把 Q1 的质量分数转换成 B6 的 `Q_score`。因此它可以完成问题三的条件性资源配置解答，同时保留正式联合模型尚未识别的边界。
