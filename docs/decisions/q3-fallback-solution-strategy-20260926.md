# 问题三退阶解答策略

状态：`RECOMMENDED_CONDITIONAL_SOLUTION`

## 1. 总判断

题目要求同时使用 (N,D,Q,p) 建立四量标度律，但现有数据缺少 A-B 逐行或批次级连接键，Q1 与 B6 的质量分数也不在同一尺度。因此，直接拟合完整四量模型并不能得到可识别、可验证的参数。

当前最合理的策略不是伪造一个联合拟合，而是把问题三拆成三层：

1. **可验证主模型**：用 M0 和 M1 完成规模、质量和预算优化；
2. **条件配比层**：把观测过的 (p) 作为离散策略情景，并报告 (Q_A(p)) 的区间；
3. **理论四量层**：给出 M3 的假设形式、文献依据和识别条件，但不把假设参数写成实证拟合结果。

## 2. 对题目要求的覆盖方式

| 题目要求 | 退阶后的回答 |
|---|---|
| 建立经典规模律 | 用 B1 拟合 M0：(L(N,D)=E+A N^{-\alpha}+B D^{-\beta}) |
| 加入质量 (Q) | 用 B6/B7 原生 `Q_score` 拟合 M1，明确其为半合成条件模型 |
| 加入配比 (p) | 用 Q1 的 (p) 和 (Q_A(p)) 做离散情景，不假装有 B 侧独立效应 |
| 给出四量模型 | 给出理论 M3-H，并做参数/尺度敏感性，不声称正式识别 |
| 边际效用和弹性 | 对 M0/M1 给出解析导数和弹性；对 (p) 给出 ilr 方向敏感性 |
| 质量与规模替代 | 用成本调整后的边际收益 (R_Q=MB_Q/MC_Q)、(R_D=MB_D/MC_D) 比较 |
| 结构性转移 | 用 (R_Q=R_D) 定义资源转移点，并用 (L_{ctx}^{crit}=6/\eta=30000) 解释注意力/训练成本转移 |
| 参数估计与验证 | B1、B6 做内部验证；B2/B3、B4/B5 做外部诊断；B9/B10 只做外推边界 |

## 3. 报告中的模型层次

### 3.1 主结果：M0

```text
L_M0(N,D) = E + A*N^(-alpha) + B*D^(-beta)
```

在预算约束下求 (N,D)，同时报告解析解、B1 支持域约束解和外推状态。

### 3.2 条件结果：M1

```text
L_M1(N,D,Q_B) = E + A*N^(-alpha) + B*D^(-beta) + G*(1-Q_B)
```

使用三类质量成本函数、三个预算和五个 C7 上下文长度，报告 (N^*,D^*,Q_B^*)、Loss、质量成本占比和边界状态。

### 3.3 配比结果：M2/P 情景

```text
Q_A(p) = sum_j p_j*q_j
```

只对已观测的六个配比候选做离散面板。A 侧配比 Loss 与 B 侧资源分配并列报告，不相加为联合 Loss。

### 3.4 理论结果：M3-H

```text
z(p) = ilr(p)
M_p(p) = exp(theta^T * (z(p)-z(p0)))
L_H = E + A*N^(-alpha) + B*(D*M_p(p))^(-beta) + G*(1-Q)
```

它用于说明配比如何改变有效数据效率，并在 (p=p_0) 时退化到 M1、进一步去掉质量项时退化到 M0。由于缺少联合数据，(G)、(	heta) 和 Q 的尺度变换只能做假设情景。

## 4. 结论分层

### 可以作为主要结论

- B1 数据内部的 (N,D) 幂律关系；
- B6/B7 原生 `Q_score` 的条件质量效应；
- 不同预算、上下文长度和质量成本函数下的资源配置；
- 参数折叠、支持域和成本族敏感性；
- C7 临界上下文长度两侧的结构变化。

### 可以作为条件结论

- 观测配比候选的资源配置面板；
- M2 部分映射、重归一化和区间情景；
- 假设质量校准下 M3-H 的 (N,D) 反事实结果。

### 必须明确不能声称

- A 侧配比对 B 侧 Loss 的独立因果效应；
- Q1 质量分与 B6 `Q_score` 的真实等价；
- 已识别的 (G_{bridge})；
- 跨 A-B 的唯一最优配比；
- 支持域外的实证全局最优。

## 5. 推荐的答题措辞

可以在正文中写：

> 由于附件 A 与附件 B 没有样本级或批次级唯一连接键，且两侧质量指标未建立共同标度，本文不对 (L(N,D,Q,p)) 的跨来源联合系数作无约束拟合。我们先在可识别的数据子问题上分别估计规模律和原生质量条件律，再将已观测配比作为离散条件策略，并给出一个可退化到前述模型的理论四量接口。四量接口的结果仅用于敏感性和反事实分析，正式参数估计需等待共同批次数据和质量尺度校准。

这样的处理仍然回答了题目要求的目标函数、边际效用、弹性、资源替代、结构性转移、预算优化和敏感性问题，同时避免把不可识别的跨来源效应写成确定结论。
