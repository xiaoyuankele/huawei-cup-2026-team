# 问题二建模状态与下一步方案

更新：幂律比较、质量增量检验和配比残差化已完成；当前结果见 [广义标度律模型 v1](q2-generalized-scaling-model-v1.md)。下文保留为早期原型记录，其“尚未完成”项目和对数线性系数不代表当前版本。

运行日期：2026-09-25

这份报告记录目前可以由数据支持的局部模型、源间校准风险，以及最终组合模型的使用边界。核心原则是：A、B 不存在逐行共同实验编号，因此不把缺失变量通过笛卡尔积补成“观测样本”；先分别验证规模、配比、质量三个局部模块，再把它们用于带标签的情景预测。

## 1. 三个局部模块的证据

### 规模模块（B1）

在 B1 的 1176 条真实 Pythia 训练日志上拟合

\[
L_{scale}=3.30095-0.13586\log N-0.17855\log D.
\]

B1 内部 MAE=0.0733、RMSE=0.1030、R²=0.9093；按参数规模留一验证时，端点规模误差更大。迁移到其他 B 源时，B2/B4/B5 的原始 MAE 分别为 1.368、0.475、0.225，说明不同来源的 Loss 标尺和模型族存在偏移。

### 配比模块（A）

用 A4/A5 的 512 条真实 1M 配方记录，对 13 个领域分别拟合去掉一个闭合约束列的 Ridge 一阶混合模型。A4/A5 训练 MAE=0.403；在同为 1M 的 A6/A7 上 MAE=0.386，优于域均值基线 0.619。到 A8/A9（60M）和 A10/A11（1B）时，绝对 Loss 误差分别为 1.514 和 3.191，说明配比方向可以审计，但 1M 的绝对截距不能直接外推到更大规模。A12–A15 是估计值，没有参与拟合。

### 质量模块（B6/B7）

B6/B7 为半合成数据；下面的留出指标反映其给定生成机制内的预测能力，不能视为独立真实训练实验对质量效应的验证。

B6 的 360 行全部包含在 B7 的 450 行中，因此完整 B6→B7 不能当作独立外部验证。修正后使用 B7 中相对 B6 不重叠的 90 个新增质量水平，并做 B7 按质量水平留一验证：MAE=0.0606 和 0.0603–0.0782，R²=0.9404 和 0.8780–0.9528。固定 `(N,D)` 的组内方向在 B6/B7 中均为“质量越高，Loss 越低”（45/45 组）。B8 的 150/150 组方向相反，必须作为冲突审计，不能与 B6/B7 无条件合并。

## 2. 源间校准审计

对 B1 模型在 B2/B4/B5 上做的均值或中位偏移修正，只是事后诊断：B2 需要约 +1.37，B4 约 +0.47，B5 约 +0.20。由于没有新来源的桥接观测，不能把这些数字固定成普适校准参数。

A6 与 A8 对同一批 256 个配方提供了直接规模对照。13 个领域的 A8−A6 平均偏移为 −1.4594，负偏移比例为 100%。这证明 A 内部存在规模相关的系统变化，但它不能恢复 B 中 `D_tokens_B` 的真实坐标，也不能替代 A/B 联合桥接实验。

Q1 的 `Q_A_topsis` 与 `quality_score_soft_proxy_0_1` 相关系数为 −0.6516。两者都是无量纲分数，但评分定义和排序不同，不能通过简单缩放互换。把两种轴分别映射到 B7 的 Q 范围后，组合情景中 `scale_plus_Q` 的中位预测差异约 0.121 Loss 单位；这应作为质量映射敏感性，而不是经验校准结果。

## 3. 当前允许的组合模型

在明确标注为情景预测的前提下，可以使用

\[
\widehat L_j(N,D,Q_A,p)
=\widehat L_{scale}(N,D)
+\widehat G(T(Q_A))
+\widehat F_j(p)
+b_{source,j},
\]

其中 `T(Q_A)` 是假设性的 Q1→B7 仿射 min-max 映射，`F_j(p)` 使用 A4/A5 的中心化配比效应。建议报告四个版本：`scale_only`、`scale_plus_Q`、`scale_plus_p` 和 `scale_plus_Q_plus_p`。最后一个版本可能重复计算由配比产生的质量信息，只能作为敏感性对照，不构成有保证的预测上下界。当前情景脚本使用 13 域平均 Loss 的配比效应；上述按领域表达式是接口方案。源偏移项尚未得到跨 A/B 经验标定。

目前的对数线性规模模块是初步基线，并非原计划中的 `E + A N^(-α) + B D^(-β)` 幂律拟合；二者尚需在相同留出划分下比较。上游 TOPSIS 与 soft 映射仍保留其审核状态，情景输出不能替代上游审核。

## 4. 模型有效性的判定标准

组合模型暂时不能用“合成表上的 Loss 拟合优度”证明。有效性应分层报告：

1. 规模模块：B1 内部留一规模验证，并报告跨源 MAE 与偏移；
2. 配比模块：A6/A7 同规模外部验证，A8/A9、A10/A11 只做方向和尺度审计；
3. 质量模块：B6→B7 非重叠新增质量水平验证、B7 按 Q 留一验证，并单列 B8 方向冲突；
4. 组合模块：只报告情景敏感性、单调性、边界外推和不同 Q 轴/源偏移假设下的预测区间。

真正识别 `L(N,D,Q,p)` 的下一步，是补充少量同一验证集上的联合桥接实验：固定若干 `(N,D)`，交叉改变 Q1 配比并同时记录真实 `Q_B` 与 Loss。没有这类观测，Q 与 p 的交互项仍不可识别。
