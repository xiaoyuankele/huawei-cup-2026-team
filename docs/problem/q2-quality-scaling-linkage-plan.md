# 问题一质量映射与问题二标度律的连接方案

## 1. 先确定连接方式

### 1.1 四个量是否在同一行

当前附件不存在一张同时含有 (N,D,Q,\mathbf p) 的原始样本表：

| 数据块 | 有哪些量 | 缺少哪些量 | 正确用途 |
|---|---|---|---|
| A4–A15 | \(\mathbf p\)、13 个领域 Loss、粗粒度 scale 标签 | 没有 `N_params_B`、`D_tokens_B`、原生 `Q_score` | 估计配比效应，做跨 scale 检验 |
| B1–B5 | \(N,D\)、Loss | 没有 \(Q\)、\(\mathbf p\) | 估计和验证规模效应 |
| B6–B8 | \(N,D,Q\)、Loss | 没有 \(\mathbf p\) | 估计质量效应；B8 另做方向审计 |
| B9–B10 | \(N,D\)、真实或估算 Loss | 没有 \(Q\)、\(\mathbf p\) | 大规模外推审计 |

所以最终会得到的是**带缺失模式的多源联合模型**，而不是一张“观测到四个量”的数据表。由 A 的配比行和 B 的规模行生成的笛卡尔积只能用于情景预测和问题三优化，不能当作新增实验样本参与拟合。

问题一与问题二之间没有可直接用于逐行合并的共同主键：

- 问题一 A4–A15 是“配方行—13 个领域 Loss”，有 `index`、17 个配比列和质量代理；
- B1/B2 是“模型—训练时刻—总验证 Loss”，有 `run_id`、`N_params_B`、`D_tokens_B`，没有配方 `index` 或 17 域配比；
- B6–B8 是 N-D-Q 半合成实验，有 `N_params_B`、`D_tokens_B`、`Q_score`、`val_loss`，没有问题一的 `index` 或领域配比。

因此不能把 A4–A15 与 B1–B10 当作两张表按行拼接。正确的连接是**分层建模连接**：问题二的 B 数据估计规模和质量响应，问题一的配比表估计领域混合响应，最后在共同的 `$N,D,Q,p$` 场景上组合预测。

## 2. 固定使用的上游质量版本

云端仓库里有两条不能静默混合的 Q1 质量链：

1. `q1-critic-topsis-20260924-r01` 是主质量评分运行，`domain_scores.csv` 的 `mean` 是 0–100 的 TOPSIS 域级质量分，运行状态仍为 `REVIEW_BLOCKED`；
2. `quality-mapping-20260925-r02-soft-handoff` 是 v2 soft 映射运行，状态为 `REVIEW`，它用聚类锚点得到另一条 0–1 质量轴，并对 11 个 inferred 域给出语义范围。

因此先建立两套带版本标签的输入，不把它们平均或拼接：

- `Q_A_topsis`：用主评分运行的域级 `mean/100`，再按 A16 的候选权重聚合到 17 个配方域；
- `Q_A_soft_v2`：使用下面的 v2 soft handoff，作为独立敏感性分支。

主评分域均值映射后的 17 域质量大致落在 0.517–0.643，而 v2 soft 域分落在 0.0029–0.5077；两条质量轴在 1214 个 A4–A15 配方上的相关系数约为 -0.652，说明它们不是同一个数值尺度，不能改列名后直接替换。

使用云端仓库的 `quality-mapping-20260925-r02-soft-handoff` 作为 v2 soft 分支：

- `scored_wide_v2_soft.csv`：1214 行 A4–A15 配方—Loss 配对；
- `mapping_v2_soft.csv`：17 个配方域到 7 个质量信号域的软映射；
- `quality_domain_scores.csv`：7 个质量域的域级质量分；
- `quality_score_soft_proxy_0_1`：v2 soft 分支质量轴；
- `quality_score_soft_low_0_1`、`quality_score_soft_high_0_1`：语义映射敏感性边界；
- `mapped_share_direct_near_direct`：该配方有多少权重来自 direct/near_direct 映射。

`quality_score_proxy_0_1` 保留作 v1 兼容性对照，`quality_score_mapped_0_1` 只做 direct/near_direct 敏感性分析。11 个 inferred 域的权重是语义先验，不是观测概率；上下界也不是统计置信区间。Q1 主评分链和 v2 soft 链都仍需人工审核，论文中必须写明版本和审核状态。

## 3. 先做数据审计，再连接

### 3.1 问题一质量轴的可识别性

问题一的

\[
Q_A(p)=\sum_{i=1}^{17}p_i q_i
\]

是 17 个配比的确定性函数。因此把完整的 17 个 `p_i` 和 `Q_A` 无约束地同时放入普通回归，会产生完全共线，不能把 `Q_A` 的系数解释为独立质量因果效应。

建议保留两个层次：

1. 配比模型使用 `p`，回答哪些领域替换影响 Loss；
2. 质量模型使用 `$Q_A$`，回答把 17 维配比压缩成质量轴是否有预测价值。

若必须同时解释两者，先对配比空间做质量方向与剩余方向分解，使用 `$Q_A$` 加上正交的 `$p_\perp$`，不要直接把 `$Q_A+p_1+\cdots+p_{17}$` 放入 OLS。

### 3.2 问题二质量数据的方向冲突

对 B6–B8 按固定 (N,D) 做组内检查得到：

| 数据 | 质量方向 | 处理 |
|---|---|---|
| B6 `supplementary_NQ_experiment.csv` | $Q$ 越高，Loss 越低；45/45 组内趋势为负 | 质量效应校准集 |
| B7 `..._expanded.csv` | 与 B6 同方向；45/45 组内趋势为负 | B6 的扩展确认集 |
| B8 `..._large.csv` | $Q$ 越高，Loss 越高；150/150 组内趋势为正 | 隔离为方向冲突/外推审计集 |

审计结果已写入 `q2_quality_scaling_linkage_audit.csv`。B8 不能在没有解释的情况下与 B6/B7 合并。优先检查其 Q 定义是否发生了反向、是否换了 Loss 生成公式、以及 `calibrated` 与 `extrapolated` 的生成口径。若无法解释，主模型不使用 B8 估计质量系数，只报告 B8 敏感性结果。

## 4. 推荐的四层模型

令 (j=1,\ldots,13) 表示问题一的 13 个 Loss 领域，令 \(\bar L_A\) 表示其等权平均。

### 层 0：B1 经典规模基线

用真实 Pythia B1 拟合：

\[
L_B(N,D)=E+A N^{-\alpha}+B D^{-\beta}.
\]

B2 或 B3 做族外/插值验证，B4 和 B5 做跨族及文献验证。这个层只估计规模效应，不把 B1 假装成含质量或配比的观测。

### 层 1：B6/B7 质量响应

在 B1 的规模基线上加入 B6/B7 的原生 `Q_score`：

\[
L_{BQ}(N,D,Q_B)=L_B(N,D)+g(Q_B),
\]

其中 $g$ 先用单调样条或低阶单调函数，避免预先强行使用某个幂律。只用 B6/B7 估计 `$g$`，B8 留作方向冲突审计。

由于问题一的 `$Q_A$` 与 B6/B7 的 `$Q_B$` 不在同一量纲，不直接把两个数值宣称为同一个质量分。建立显式的单调运输映射：

\[
Q_B=T(Q_A;\theta),\qquad T'\ge 0,
\]

主版本采用固定的分位数运输，敏感性版本采用单调线性/等距映射。所有映射参数只在 B6/B7 的质量校准阶段固定，不使用 A6–A15 或 B8 反调。

建议输出四套质量输入：

- `Q_A_topsis`：主评分域均值经 A16 聚合得到的质量轴，作为首选候选主输入；
- `Q_A_soft`：问题一 v2 soft 质量轴；
- `Q_A_low/high`：v2 inferred 映射边界经过同一 `$T$` 后得到的区间；
- `Q_A_direct`：只使用 direct/near_direct 的敏感性版本。

### 层 2：问题一配比响应

在 A4–A11 的真实配方—Loss 数据上估计：

\[
L_{Aj}(s,p)=a_j+h_j(\log s)+f_j(p),
\]

其中 `$f_j(p)$` 首选一阶 Scheffé 混合模型，二阶组合项只用 ridge/elastic net 作为扩展。A4/A5 用于拟合；A6–A11 用于外部检验；A12–A15 只做跨规模外推审计。

此层回答领域配比如何影响 Loss；不把 A12–A15 的估算 Loss 用来调参数。

### 层 3：统一预测接口

最终把两类效应组合为：

\[
\widehat L_j(N,D,Q_A,p)
=L_B(N,D)+g\bigl(T(Q_A)\bigr)+f_j(p)+r_j(N,D,Q_A,p),
\]

其中 `$r_j$` 先设为 0。只有在外部检验显示质量效应随规模稳定变化时，才增加质量—规模交互：

\[
r_j=\delta_j T(Q_A)\log N+\zeta_j T(Q_A)\log D.
\]

交互项必须通过 A6–A11 和 B2/B3 的留出验证，不能仅凭训练集拟合优度保留。

## 5. 实际文件级连接表

建立一个统一的预测表，而不是伪造原始数据的行级连接：

| 输出字段 | 来源 | 含义 |
|---|---|---|
| `N_params_B`, `D_tokens_B` | B1/B2/B4/B5/B9 | 规模坐标，统一为十亿单位并保留实际 FLOPs 换算 |
| `Q_B_native` | B6/B7 | B 数据原生质量实验坐标 |
| `Q_A_soft`, `Q_A_low`, `Q_A_high` | Q1 v2 handoff | 配方行的质量代理及语义范围 |
| `p_*` | `scored_wide_v2_soft.csv` | 17 域归一化配比 |
| `val_loss` | 各数据集 | 观测、半合成或估算标签，必须保留 provenance |
| `source_role` | manifest | `fit`、`validation`、`external`、`extrapolation` |
| `quality_provenance` | Q1 mapping | `official`、`inferred_low`、`range_sensitive` |

统一预测表中的每一行表示一个可评估场景 `$\,(N,D,Q,p)\,$`，不是声称这个场景在原始附件中被同一实验同时观测过。

## 6. 验证顺序

1. B1 拟合经典标度律，B2/B3、B4、B5 做规模外部验证。
2. B6/B7 在固定 (N,D) 下估计质量响应，确认 `$Q$` 的方向和单调性。
3. 用 B8 做方向冲突审计；若仍为反向，主结论只基于 B6/B7，并将 B8 作为数据口径限制。
4. A4/A5 拟合配比效应，A6–A11 检验，A12–A15 外推审计。
5. 固定 `$T$` 和质量版本后，生成统一 `$\,(N,D,Q,p)\,$` 场景预测。
6. 比较嵌套模型：规模 → 规模+质量 → 规模+配比 → 规模+质量+剩余配比。
7. 只在外部误差稳定下降时加入质量—规模交互。

## 7. 需要在论文中明确写出的限制

- A 与 B 没有逐行主键，连接是模型层连接，不是原始观测的直接合并。
- Q1 的 `$Q_A$` 是由配比和域级质量分确定性计算的代理量，不能单独宣称为独立质量因果变量。
- B6/B7 是半合成质量实验，B8 的质量方向与 B6/B7 冲突，不能无条件合并。
- B9 是真实大模型元数据，B10 是估算 Loss；两者只能用于锁定模型后的外推讨论。
- 质量映射中的 inferred 区域要报告上下界和覆盖比例，不能只给一个没有不确定性的点估计。

## 8. 推荐主线

第一阶段使用 B1 + B6/B7 + `Q_A_topsis` + A4–A11，形成“规模基线—质量响应—配比响应”的三层结果；`Q_A_soft_v2`、`Q_A_direct` 和语义上下界作为预先登记的质量敏感性。B8、A12–A15、B9/B10 只作为敏感性和外推审计。这样既能把仓库已有的质量评分和配比映射接入问题二，又不会把没有共同主键的数据伪装成一次联合实验。
