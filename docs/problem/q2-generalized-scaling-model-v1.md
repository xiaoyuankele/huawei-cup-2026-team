# 问题二：广义标度律模型 v1 与参数结果

后续实验：[来源与配比迁移改善结果](../../experiments/runs/q2-transfer-improvement-20260925/report.md)已完成。B2截距校准和60M配比校准获得局部支持，1B未超过简单基线。本页与v1参数保留原版本，校准候选未自动合入。

本轮完成规模模型比较、质量增量检验和避免重复计入的组合接口。采用“幂律规模基线＋质量响应＋剩余配比响应”，交付可复算的条件预测模型。它尚不是由同一批四变量实验识别出的联合定律。

## 1. 采用的公式

\[
\widehat L_B(N,D,Q_A,p)=
1.689798+0.353980N^{-0.339977}+1.240306D^{-0.279878}
-0.361995\lambda_Q[T(Q_A)-T(Q_{A0})]
+\lambda_p\,\widehat w^\top r(p).
\]

- `N` 为十亿参数数，`D` 为十亿训练 token 数，不能直接代入未换算的原始数量。
- 输出为以 B1 Loss 为参照的情景预测；不是 A 的 13 域平均 Loss 的绝对值。
- `Q_A=qᵀp` 来自 Q1 域级质量与 17 域配比；默认展示 TOPSIS 候选轴，soft 轴单列敏感性。沿用上游 TOPSIS `REVIEW_BLOCKED`、soft `REVIEW` 状态，不将其视为已审核定稿。
- `λ_Q`、`λ_p` 是跨源迁移强度。示例取 1，另报告取 0 或将 `λ_p` 减半的对照。这些值是情景假设，不是从 A/B 联合实验估计出的参数；现有扫描也不是置信区间。
- 不拟合 `N×Q`、`D×p` 等跨块交互项。现有分块观测不足以支持这些参数。

### 质量映射

只用 A4/A5 训练配方确定 `q_min`、`q_max`：

\[
T(Q_A)=\mathrm{clip}\!\left(0.1+0.9\frac{Q_A-q_{min}}{q_{max}-q_{min}},\,0.1,1\right).
\]

该映射将 Q1 代理分数送入 B7 的控制分数范围；不是成对观测下的经验标定。超出训练范围时显式标记截断。两套轴分别确定映射，不合并评分。与旧情景脚本相比，映射范围现在只来自训练配方，不再由所有观测配方决定。

### 剩余配比项：避免把 Q 与完整 p 相加

设 `p₀` 为 A4/A5 训练配比均值，`Q_A0=qᵀp₀`，在训练数据上估计

\[
v=\frac{\sum_i(Q_{Ai}-Q_{A0})(p_i-p_0)}{\sum_i(Q_{Ai}-Q_{A0})^2},
\qquad
r(p)=p-p_0-v(Q_A-Q_{A0}).
\]

`r(p)` 是去掉与质量线性相关部分后的配比残差。训练集中它与 Q 的样本协方差为零，且 `1ᵀr=0`、`qᵀr=0`。它不意味着统计独立，也不意味着因果效应可识别。

`w` 来自 A4/A5 上对 13 域平均 Loss 的 Ridge 拟合（512 行、17 个中心化配比、惩罚系数 `10⁻⁵`）。完整拟合可分解为质量相关部分与 `wᵀr`；组合时用 B7 的质量响应替换前一部分，避免直接叠加同一个质量方向。所有载荷和系数见 `mixture_coefficients.csv`，参考配方见 `model_parameters.json`。

## 2. 模型取舍的实际依据

### 规模：保留幂律，替换对数线性原型

只使用 B1 拟合。8 个参数规模逐一留出，两个模型使用完全相同的划分；表中汇总所有留出预测，不使用训练误差作选择依据。

| 模型 | 留出 MAE | 留出 RMSE |
|---|---:|---:|
| 对数线性 | 0.090739 | 0.123077 |
| 经典幂律 | 0.000108 | 0.000151 |

幂律的留一规模指数范围约为 `α=0.339958–0.340067`、`β=0.279861–0.279896`。附件内拟合近乎精确；这说明所给文件与该公式高度一致，不能据此推断真实训练噪声接近零。数据说明将 B1 标为真实，本轮未独立核验其原始采集链。

锁定 B1 参数后的外部 MAE：B2 为 1.1784、B4 为 0.2273、B5 为 0.1707。B2 仍有明显源间偏移，因此不宣称绝对 Loss 可无条件跨来源迁移。

### 质量：加入 Q 有增量，但证据来自半合成数据

冻结 B1 幂律参数，仅在各折 B6/B7 训练行中估计来源截距及质量系数。比较基线包含同样的来源截距，避免把“截距修正”算作质量改善。

| 验证方案 | 幂律＋来源截距 MAE | 再加入线性 Q 后 MAE |
|---|---:|---:|
| B6 → B7 不重叠的 90 行 | 0.057491 | 0.044603 |
| B7 留出完整 Q 水平，450 行汇总 | 0.110407 | 0.057046 |
| B7 按 `(N,D)` 分组五折，450 行汇总 | 0.101965 | 0.057322 |

按 `(N,D)` 分组五折时，线性 Q 的 RMSE=0.073857，优于 log Q 的 0.080589，因此保留线性项。该分组结果也用于形式选择，属于模型开发验证，不是未使用过的最终独立测试。

在完整 B7 上估计的质量系数为 `−0.361995`。B7 相对 B1 的来源截距约为 `+0.163790`（以 `Q=0.55` 为参考），仅用于 B7 局部拟合，不直接加入 A/B 组合。B6/B7 有重叠，不把两者重复堆叠增加样本量。B8 保持隔离；本轮不使用它估计质量方向。

### 配比：同规模有价值，跨规模幅度迁移有限

以下指标针对每行 13 域平均 Loss；与旧报告“分别预测 13 域后汇总误差”的指标口径不同，不能直接横向比较。

| A6/A7 同规模验证，256 行 | MAE |
|---|---:|
| A4/A5 训练均值基线 | 0.225599 |
| A4/A5 完整配比模型 | 0.180679 |
| TOPSIS 剩余配比项＋训练截距 | 0.184309 |
| 用 B7 质量项替换 A 质量项＋剩余配比＋A 训练截距 | 0.180795 |

最后一行是有限的组件替换检验：保留 A 的训练截距，冻结 B7 质量斜率及训练配方映射，检验 A6/A7。它支持当前替换没有明显损害同规模预测，但没有验证 B1 基线与 A 的绝对 Loss 对齐。

A6/A8 的 256 个相同配方，其观测平均 Loss 的 Spearman 相关系数为 0.9658，说明排序在 1M 与 60M 之间较稳定。完整配比模型在 A8 的预测排序相关系数为 0.5584；扣除各自均值后的 RMSE 为 0.1943，而常数模型为 0.2189。

到 A10/A11 的 1B 样本，完整配比模型的中心化 RMSE 为 0.1615，劣于常数模型 0.0519。故不能把 1M 的配比效应幅度固定迁移至任意大模型。中心化指标使用测试集均值，只用于描述形状误差，不是可部署的偏移校准，也未用于调节 `λ_p`。

## 3. 如何使用当前模型

1. 以幂律项作为 B1 范围内的主规模预测，支持范围约为 `N=0.070542–11.965825B`、`D=0.134–299.893B`。范围内也不意味着每种联合输入都经过实验验证。
2. 引入 Q1 质量及配比时，使用上述完整公式，并报告 TOPSIS/soft 两套质量轴以及迁移强度情景。
3. 组合预测不写入观测 Loss 列，不用于重新拟合，不据其自身拟合优度宣称验证成功。
4. 此处 Q 是 p 的确定性代理，无法独立改变 Q 而保持 p 不变；接口支持含四类字段的预测，但不能据此识别四个独立变量的因果作用。
5. 目前完整模型可作为后续资源配置的条件目标函数。由于修正项暂时与 N、D 可加分离，在固定配比且没有数据成本或规模交互时，Q、p 不会改变最优 N/D 分配；不得宣称它们已被证明改变计算最优比。
