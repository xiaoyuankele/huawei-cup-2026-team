# 问题四实验计划（统一版）

## 研究目标

使用附件 C 的逐任务 C8 评测分数和模型规模信息，预测未来 12 个月的能力前沿，并区分可验证的短期预测、模型构成敏感性和算力外生情景。问题二、问题三不作为问题四建模的前置条件，只在情景层提供规模弹性。

## 冻结协议

- 分析窗口：2024-06 至 2025-03，共 10 个月；
- 主分数：C8 详细 JSON 中 IFEval、BBH、MATH、GPQA、MUSR、MMLU-PRO 六项一级指标等权平均，乘 100；
- 前沿：每月模型横截面的 95% 分位数；
- 敏感性分数：Leaderboard `Average`；
- 时间外切分：按月份顺序 70/30，即前 7 个月训练、后 3 个月测试；
- 短期预测长度：h=1 和 h=3；
- 正式情景期：12 个月；当前数据不足以完成真实 h=12 回测；
- 类型：pretrained、chat、fine-tuned、merge 进入主分析，pretrained-only 作为敏感性；
- 算力倍率：1.0×、1.5×、2.3×、4.0×、5.0×/年；类型比例对 pretrained/chat 分别做 ±10 个百分点扰动。

## 数据审计

排除历史来源与不完整任务记录，不把题面预填系数、隐藏文字和提示性答案作为特征或标签。参数量小于等于 0 的记录不进入对数变量；训练数据量、训练算力和评测版本缺失时不做均值填补。C8 parquet 中的 `Base Model` 用于后续家族留出验证，namespace 只作为发布方聚类代理。

## 实验流程

1. 构造六任务等权 C8 分数并按模型、月份去重；
2. 计算月度 q90/q95 前沿，比较最近值、近三月均值、扩展线性趋势和最近四点线性趋势；
3. 按 70/30 时间顺序评估 h=1/h=3，报告 MAE、RMSE、Bias 和 R²；
4. 拟合 q=0.90/0.95 的低复杂度面板分位数模型，主指标使用 pinball loss 和分位覆盖率；
5. 做任务级、留一任务、类型分层、时间置换和 cluster bootstrap 检查；
6. 将问题三的规模弹性作为外生输入，生成平台型和趋势型 12 个月算力情景；
7. 对所有情景做支持域、类型比例和数据漂移限制说明。

## 结果接受规则

模型只有在时间外 pinball loss 改善且分位覆盖率接近目标时，才可作为 q95 主候选。普通 R² 和 MAE 只能作为辅助诊断。h=3 只有一个测试点时不做 R² 或显著性结论；12 个月结果只能写作条件情景。

## 旧版结果定位

早期的 2024 年训练、2025 年测试以及 0%/25%/50% 算力运行保留在 `q4-frontier-20260926-r01`，用于方法开发和年度兼容性检查。最终汇报统一引用 `q4-system-20260926-r01` 的聚合指标。
