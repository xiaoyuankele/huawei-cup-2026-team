# 问题四：短期稀疏前沿预测的稳健性实验

> **结果定位：历史探索。** 本文的 7 点滚动结果来自早期运行。当前主协议新增 h=1/h=3 的 70/30 月份验证，主表以 `q4-system-20260926-r01/metrics/q4_protocol_rolling_horizon_metrics.csv` 为准。

本轮实验仍只使用附件 C 的 2024-06 至 2025-03 同一来源时段。预测对象是月度模型横截面的 95% 分位前沿；C8 主指标为六个任务一级指标的等权平均，官方 `Average` 作为敏感性指标。每个滚动预测只使用测试月份之前的数据。

## 1. 预测器敏感性

在 10 个月时间轴上，改变最小训练窗口（3 或 5 个月）和预测器。结果见 `experiments/runs/q4-frontier-20260926-r01/artifacts/robustness/robustness_metrics.csv`。

- C8 指标：线性趋势在 7 个测试点上的 MAE 为 0.857（窗口 3），窗口 5 时为 0.761；最后值法分别为 0.999 和 1.236；近三月均值为约 2.00。线性趋势的优势只能说明在这组很短的历史上滚动一步预测较贴合，不能直接支持 12/24 个月线性外推。
- 官方 `Average`：窗口 3 时近三月均值 MAE=1.638，优于最后值 1.712 和线性趋势 3.172；窗口 5 时近三月均值 MAE=1.524，仍优于最后值 1.596 和线性趋势 1.808。
- 因而两个指标对模型排序不一致，说明评价口径本身是重要敏感性来源。正式预测应保留平台型（最后值/近三月均值）与趋势型两类情景，而不应只报告线性趋势。

注意：C8 只有 7 个或 5 个滚动测试点，以上是描述性误差，不进行显著性检验或模型优胜宣称。

## 2. 月度 95% 前沿的不确定性

对每个月的模型横截面进行 2000 次模型重采样，得到 q95 的样本不确定性区间。结果见 `experiments/runs/q4-frontier-20260926-r01/artifacts/robustness/c8_equal_task_frontier_bootstrap.csv`。

- 2024-06：45.80，bootstrap 95% 区间约 [41.48, 47.35]；
- 2024-12：50.25，区间约 [49.66, 50.91]；
- 2025-03：54.16，区间约 [52.24, 54.70]。

后期月份的区间通常较窄，但这只反映当月横截面样本量和离散程度；它没有覆盖数据源更换、模型提交构成变化、评分规则变化等时间外风险。

## 3. 模型类型分层

分层结果见 `experiments/runs/q4-frontier-20260926-r01/artifacts/robustness/c8_type_stratified_q95.csv`。整体 q95 的上升不能直接解释为单一的“技术进步”：不同月份的 chat、pretrained、fine-tuned 和 merge 模型占比在变化，2025 年初后 fine-tuned 与 merge 记录占比明显提高，而 pretrained 记录较少。分层 q95 也存在明显差异，因此后续应把 `Type` 作为协变量或分层条件，而不是把所有模型当成同质重复观测。

## 4. 对后续主模型的约束

下一步主模型采用“类型分层 + 时间趋势 + 参数规模/数据规模（可用时）”的低复杂度面板模型，并将平台型、趋势型和随机前沿型结果并列。12/24 个月结果报告为情景区间；当前数据不足以支撑单一精确点预测，更不足以声称因果分解已经完成。
