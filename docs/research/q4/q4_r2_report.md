# 问题四 R² 补充评价

分位数回归的正式拟合指标是 pseudo-(R^2)，不是普通最小二乘 (R^2)。结果见 `experiments/runs/q4-frontier-20260926-r01/artifacts/error/r2_metrics.csv`。

详细 C8 95% 分位模型：

| 模型 | 训练 pseudo-(R^2) | 测试普通 (R^2)（训练均值基线） |
|---|---:|---:|
| 截距 | 0.000 | −1.991 |
| 参数 | 0.332 | +0.190 |
| 参数+类型 | 0.374 | +0.162 |
| 参数+时间 | 0.413 | −0.608 |
| 参数+时间+类型 | **0.431** | −0.431 |

完整模型的 pseudo-(R^2) 最高，但测试普通 (R^2) 为负。这并不矛盾：完整模型优化的是 95% 分位 pinball loss，预测的是上尾，不是条件均值；普通 (R^2) 会惩罚其有意的上移。参数模型测试普通 (R^2) 为正，但其 95% 覆盖率只有 87.3%，不满足上分位校准要求。

因此论文中可以报告 pseudo-(R^2) 作为拟合辅助指标，但模型选择仍以时间外 pinball loss 和分位覆盖率为主，不能用普通 (R^2) 单独决定模型优劣。
