# E1：边际效用与弹性执行方案

状态：执行前配置冻结；结果另见对应run。目标是完成题目中的边际效用与弹性分析，并验证解析计算与冻结v1预测接口一致。本轮不重拟合、不改变质量映射、不解释为因果识别。

配置：[q2-e1-marginal-elasticity.json](../../../configs/q2-e1-marginal-elasticity.json)。参考规模N=1 B、D=100 B；参考配方取A4训练均值。TOPSIS与soft分别处理，λQ、λp的0/0.5/1只构成敏感性情景。

## 分析和验收

1. 在B1边际支持范围内建立41×41规模网格，计算Loss、N/D一阶导数、正的边际收益、二阶导数及完整Loss弹性。网格不是联合观测；边界的外侧差分只用于公式核验，不作为数据内验证。
2. 用两个步长的中心有限差分核对冻结预测接口的一阶导数；核对曲率为正、规模收益递减和参数单位换算。使用既有8个留一规模参数做敏感性，不构建置信区间。
3. 区分B质量坐标z、A质量代理QA及实际配比变化。计算截断内部、外部和边界的单侧导数；边界没有普通双侧导数时保存空值和明确状态。
4. 在训练均值配方上验证所有17×16有向域转移。每个差分端点提供非负训练配方组合的存在性检查，不仅检查单列范围。额外构造沿p对Q回归载荷的局部路径，核对固定残差下QA偏导。
5. 对全部512个A4配方、两条质量轴及9组λ组合计算条件弹性，检查假设影响的是哪些量。配方标签仅提供特征，原始Loss不参与分析。
6. 输出数值表、验证记录、公式说明、两张科学图及证据边界。新增E1实验索引和候选主张，保留独立评审待定。
