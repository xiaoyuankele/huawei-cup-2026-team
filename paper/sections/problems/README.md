# 按题目顺序组织论文

本目录是论文叙事层。每一道题对应一个正文文件，文件名按题号排序：

```text
problem-01.tex
problem-02.tex
problem-03.tex
```

`paper/main.tex` 通过 `sections/problem-order.tex` 按编号装配这些文件。题目数量确定后，只需要新增或删除对应的 `problem-XX.tex`，不需要把论文拆成“数据、模型、实验、结果”四个跨题目章节。

每个问题文件内部统一采用以下顺序：

1. 问题分析与输入输出定义；
2. 模型假设、变量和目标函数；
3. 算法、求解流程或实现细节；
4. 结果、图表和检验；
5. 不确定性、失败情况和问题边界。

问题之间存在依赖时，必须在任务卡和问题文件中写明前一问题的输出如何成为后一问题的输入。例如：`Q1` 的清洗数据或估计参数进入 `Q2`，对应的输入输出文件、`run_id` 和 manifest 必须可回链。

复制 `problem-template.tex` 创建实际问题文件。模板文件本身不被 `main.tex` 编译。

## 与研发工作包的关系

`WP-A/WP-B/WP-C` 仍然用于分配数据、模型、验证和图表实现，但它们是后台执行标签，不是论文顶层章节。一个问题可以由多个工作包协作完成；一个工作包也可以服务多个问题。最终正文只按 `problem-01`、`problem-02` 的题目顺序呈现。
