# 图 1｜各领域样本质量评分分布

基于 A1、A2、A3 全量质量信号的 CRITIC–TOPSIS 样本得分，合并去重后共 261,086 个样本。领域按中位数降序排列。每行上方浅青色轮廓为使用该域全部样本计算的高斯核密度，带宽统一为 1.2 分，密度按各域峰值归一化以便比较形状，其高度不表示样本数；样本量标于领域名称下方。下方箱体为第 25–75 百分位数，深色竖线为中位数，暖色菱形为均值，须表示 1.5 倍四分位距界限内的最远观测值，所有界限外观测均以空心圆保留。分数越高表示当前代理指标体系下综合得分越高，不代表经人工真值验证的绝对质量。


## 数据与计算口径

原始文件记录共 272,505 条，覆盖 A1、A2、A3；11,419 条为跨集重复记录。检查重复 ID 的领域及全部 16 项归一化指标完全一致后，按已有评分运行的口径保留 261,086 个唯一 ID。全部唯一样本参与领域汇总，没有为作图抽样或筛掉异常点。

沿用运行 `q1-critic-topsis-20260924-r01`。归一化边界和 CRITIC 权重仅以 A1 拟合集 40,919 条估计，其他样本使用相同参数。模型先计算样本得分，再对域内样本求算术平均；总体均分按唯一记录数加权。图 2 的领域指标均值用于描述指标画像，不是重新计算 TOPSIS 的输入。

## 图 2：各领域的质量指标画像

文件：`figure02_indicator_heatmap_nature`。

**图注。** 全量去重样本在 7 个领域、16 项质量指标上的方向统一及归一化均值。每格为一个领域内对应指标的样本均值，所有单元格共用 0–1 色标，数值保留两位小数。3 项负向指标已逆向；其均值越高表示原负向特征越少。领域顺序与图 1 一致。没有逐行重缩放或聚类重排。

**阅读重点。** 可同时看到不同领域的优势和弱项，例如 arXiv 在当前归一化尺度上的整洁度均值较高，而 GitHub 的部分自然语言相关指标较低。这属于既定指标体系下的画像，不能直接推出某一领域具有普遍较高或较低的真实质量。DSIR 表示目标语料亲和度，不能单独等同于文本质量。格内颜色不是指标对总分的可加贡献，也不能单凭域级均值识别样本级指标冲突。

来源：`figure02_domain_indicator_means.csv`，16 × 7 个未按显示精度舍入的均值。

## 图 3：A1 与全量领域评分对照（重绘版）

文件：`figure03_A1_full_comparison_nature`。

**图注。** a，A1 与全量去重样本的领域平均质量评分；空心圆为 A1，实心菱形为全量，旁侧数值为全量均分，领域名称下列出样本量变化。b，精确到三位小数的全量减 A1 均分差值。两面板采用不同横轴尺度，以兼顾绝对分数和小幅变化的可读性。点表示确定的描述性均值，不是置信区间。

来源：`figure03_04_domain_comparison_and_shares.csv`。

## 图 4：领域构成变化与总体均分分解

文件：`figure04_composition_decomposition_nature`。

**图注。** a，A1 与全量去重数据的领域样本占比。b，按“先替换领域均分、后替换领域占比”的顺序分解总体均分变化。设领域 d 的 A1 和全量占比分别为 p_A,d、p_F,d，均分为 μ_A,d、μ_F,d，则域内项为 Σ p_A,d(μ_F,d−μ_A,d)，构成项为 Σ(p_F,d−p_A,d)μ_F,d；两项之和等于总体均分变化。

**阅读重点。** 总体均分从 60.947 降至 54.232，变化 −6.715 分。其中固定 A1 占比时的域内项为 −0.012 分，构成项为 −6.703 分。GitHub 的样本占比从 19.52% 增至 78.04%，使总体均分更接近该领域均分。因此，全量总体均分下降主要反映领域构成改变，不能解释成所有领域的样本质量都变差。该分解依赖所选替换顺序，是描述性恒等分解，不是因果估计。

来源：`figure03_04_domain_comparison_and_shares.csv`、`figure04_decomposition.csv`。

## 图 5：CRITIC 权重

文件：`figure05_critic_weights_nature`。

**图注。** 在 A1 拟合集上估计的 16 项 CRITIC 权重，按权重降序排列，暖棕虚线表示 16 项指标等权时的 6.25%。CRITIC 同时考虑指标离散程度和相关结构，权重之和为 1。

**阅读重点。** 句末标点行比例、整洁度、无广告倾向的权重分别约为 8.91%、8.00%、7.75%。权重表示当前样本和指标集合下的信息结构，不代表因果重要性或普遍适用的重要程度。主模型在平方距离求和中使用一次 w_j，即 d+ = sqrt[Σw_j(1−z_j)²]、d− = sqrt[Σw_jz_j²]，评分为 100d−/(d+ + d−)。不能把权重直接解释为各指标对最终得分的可加贡献。

来源：`figure05_weights.csv`。

## 图 6：评价方案的排序敏感性

文件：`figure06_model_sensitivity_nature`。

**图注。** 在相同的 261,086 个唯一样本上，5 个变体分别与主模型 CRITIC 加权距离 TOPSIS 对照。a，Spearman 排序相关系数，横轴为 0.96–1.00 附近的局部尺度；b，平均绝对百分位排名变化，以百分点计；c，百分位排名绝对变化至少 20 个百分点的样本比例。行按平均排名变化升序排列。主模型自身对照为 1、0、0，未重复绘制。20 个百分点为描述性阈值。

**阅读重点。** CRITIC 加权和与主模型最接近，ρ = 0.9990；去除 3 项负向指标后的平均排名变化最大，为 4.79 个百分点，其中约 2.78% 的样本变化至少 20 个百分点。所有相关系数虽较高，仍有部分样本对模型或指标选择敏感。该图不评价准确率，不能用来替代题目要求的“不同质量指标之间的冲突分析”。

**变体定义。** CRITIC 加权和：相同指标及权重，改为线性加和。等权加和：16 项等权求和。TOPSIS 权重平方：距离内使用归一化后的 w²。去除 DSIR：去除 3 个目标亲和度指标；去除 3 项负向指标：去除无字母词比例、高频二元组和三元组占比。删指标变体在保留指标上重新归一已有权重，没有重新拟合 CRITIC。

来源：`figure06_sensitivity.csv`。其中 `mean_abs_rank_gap_pp` 已为百分点，`rank_gap_ge20pp_rate` 转为百分比时乘以 100。
