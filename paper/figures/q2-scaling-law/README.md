# 第二问论文配图

六张图沿用仓库现有论文图的白底、深灰文字、蓝绿色主色和暖橙色对照色。图内仅保留坐标、刻度、必要图例和分面标识；图题、解释和限制条件放在下方图注，插入论文时将图注作为正文文字排在图片下面。图宽按双栏 183 mm 设计。每张图提供可编辑的 SVG、PDF，以及 600 dpi PNG、LZW 压缩 TIFF。

## 建议放入论文的图注

**图 1　B1 数据的留一参数规模验证。** 每次留出一个参数规模，共 8 折，每折 147 行。两种模型的留出 MAE 以独立点表示；横、纵轴均使用对数刻度。点之间没有插值或趋势连线。该图只说明 B1 内部的跨规模表现，不能单独证明跨来源泛化。

**图 2　引入质量变量 Q 后的误差变化。** a，三种验证协议下，含相同来源截距的规模基线与加入 Q 的模型的汇总 MAE；细线只连接同一协议的两个精确汇总值。b，每个点代表一个留出折的 MAE 改善量（基线减去加入 Q 后的 MAE），零线表示无改善。B6→B7 仅使用与 B6 不重叠的新增 90 行；B6/B7 属半合成数据。

**图 3　模型向其他来源迁移时的外层误差。** a，B2；b，A 60M；c，A 1B。实心点为全部外层留出行汇总的 MAE，空心点为各外层折的 MAE；嵌套选择仅由内层数据决定校准形式。各折和各模型之间均未连接成线。A 1B 上嵌套选择的汇总 MAE 高于均值基线。

**图 4　不同参数规模下配比响应的验证。** 对 A 1M、60M 和 1B，比较完整配比模型与均值基线在留出配比上的中心化 RMSE。两类点按规模并列，未连成趋势线。该指标扣除测试集均值，只用于诊断配比响应形状，不能作为无需目标标签的部署误差。

**补充图 1　质量指标与 Loss 的组内方向。** 固定参数规模 N 和数据量 D 后，显示 B6、B7、B8 各组 Q–Loss Spearman 相关系数的中位数；竖线为零相关。B7 包含 B6，二者不应被视为独立实验；B8 的来源分层仍需进一步核验。

**补充图 2　主拟合范围与大模型材料的参数规模。** 横线端点分别是 B1 主拟合、B9 元数据和 B10 基线材料中实际记录的最小与最大参数规模；虚线标出 B1 最大规模。B9 不含用于该图的 Loss 验证，B10 的 Loss 为估算值，因此范围延伸不能视作预测验证。

## 复现与数据核查

```bash
MPLCONFIGDIR=/tmp/q2-mpl /opt/anaconda3/bin/python plot_q2_figures.py \
  --repo /path/to/huawei-cup-2026-team \
  --out /path/to/output/figures
```

`figure_manifest.json` 记录输入文件 SHA-256、每图使用的行数及输出名称。绘图源码只读取仓库已冻结的数据表，按明确的题目模块和模型对照筛选行；没有重新拟合、随机抽样或虚构观测。图中没有把 B10 估算 Loss 用作拟合数据，也没有把条件情景预测画成观测值。

所有图片均经逐张目视核查。保留的细线只表示同一验证协议下的成对数据，或直接记录的参数规模范围及其端点；不同规模、折或来源的点不连线。仓库主目录及原始数据未修改。
