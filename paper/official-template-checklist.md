# 2026 LaTeX 模板核对表

项目使用 `paper/template/` 中导入的 2026 GMCMthesis 模板，并保留上游的官方格式核对材料。最终提交仍以组委会最新通知和附件为准。

## 版式

- [ ] `main.tex` 已填写正式队伍编号、学校和三名成员姓名
- [ ] 首页、封面、校徽、摘要页和关键词位置符合当届模板
- [ ] 页码从摘要页按要求开始，封面不显示页码
- [ ] 页边距、字号、标题层级、图表标题和参考文献样式已复核
- [ ] 摘要篇幅、关键词数量和正文总页数符合当届要求

## 内容与匿名

- [ ] 论文中的题号、模型、数据版本、`run_id` 和图表编号彼此一致
- [ ] 正文没有不应公开的个人信息、账号、路径、密钥或原始数据
- [ ] 需要匿名的版本不包含学校、成员和队伍编号等身份信息

## 交付

- [ ] 使用 XeLaTeX 完整编译且无致命错误
- [ ] 最终 PDF 经过双人检查并计算 SHA256/MD5
- [ ] PDF 文件名、程序附件、结果附件和上传回执已归档到 `deliverables/`
