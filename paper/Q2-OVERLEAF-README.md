# 问题二 Overleaf 编译入口

将仓库的 `paper/` 目录作为 Overleaf 项目根目录，主文件选择 `q2-overleaf.tex`，编译器选择 **XeLaTeX**。

该入口使用仓库中的 `template/gmcmthesis.cls`、`commands.tex`、`sections/drafts/q2-complete.tex` 和 `figures/q2-scaling-law/` 图件。正式队伍编号、学校和成员信息仍是占位符，需在 `q2-overleaf.tex` 中替换。

问题二正文明确区分了：

- B1/B6/B7 的分项检验；
- 质量—参数替代的可行路径；
- A--B 质量桥接覆盖缺口；
- B9/B10 的范围外推审计；
- B8 方向冲突和 B4/B5 分层迁移异质性。

这些结果均为冻结模型下的条件诊断，不应表述为四变量联合实验的外部验证。
