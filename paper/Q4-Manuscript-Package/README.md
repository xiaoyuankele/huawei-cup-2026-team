# 问题四论文完整包

本包对应问题四当前统一结果，适用于协作仓库归档、Overleaf 上传和论文审阅。

## 内容

- `q4-overleaf.tex`：GMCM2026 模板下的独立编译入口；
- `sections/drafts/q4-frontier-prediction.tex`：按最新大纲整理的正式正文；
- `figures/q4/`：三份 PDF 矢量图、图注、figure contract、QA 报告和源数据；
- `docs/research/q4/q4_manuscript_draft_zh.md`：对应的中文研究稿与结果记录；
- `template/`：最小 GMCM2026 模板依赖。

在 Overleaf 中选择 XeLaTeX，并将 `q4-overleaf.tex` 设置为主文档。队伍编号、学校和成员信息仍需在主文档中填写。完整的 PNG/TIFF/SVG 出版备份仍保留在仓库 `paper/figures/q4/`，本包使用 PDF 矢量图以保持体积可控。
