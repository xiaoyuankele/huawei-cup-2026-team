# 问题四 Overleaf 编译包

1. 将本目录上传到 Overleaf，或把其中内容作为项目根目录。
2. 将 `q4-overleaf.tex` 设为 Main document。
3. 编译器选择 XeLaTeX。
4. 编译依赖包括 `template/gmcmthesis.cls`、`template/figures/`、`commands.tex`、`sections/drafts/q4-frontier-prediction.tex` 和 `figures/q4/` 下的三份 PDF 图件。

队伍编号、学校和成员信息仍需在 `q4-overleaf.tex` 中填写。完整 PNG/TIFF/SVG 图件和源数据保留在仓库的 `paper/figures/q4/`，不属于最小编译包。
