# Q3 Q conditional exploratory run

运行号：`q3-q-conditional-20260925-r01`。本运行在 B6/B7 M1 半合成敏感性模型上，把 `Q` 作为决策变量，分别比较附录 B 的指数、幂函数和对数渐进质量成本。`Q0=0.1`，Q 上界取 B6 观测上界 0.9；N、D 限制在 B1 支持范围，`Lctx` 取 C7 观测值。
