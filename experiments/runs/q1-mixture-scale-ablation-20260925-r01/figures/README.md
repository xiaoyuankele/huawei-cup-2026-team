# 纯配比模型的规模修正对照图

## 绘图契约

- 核心问题：直接使用完整 17 域配比的模型在加入规模修正后，跨表预测误差如何变化，以及估算外推表是否支持相同结论。
- 证据链：a 展示 ilr-Ridge；b 展示二阶 Ridge。两个面板的区别是配比函数形式，指标、校准策略、评价数据和纵轴范围保持一致。图不预先指定胜者。
- 架构：定量双面板对照；主指标为全部样本、全部 13 个响应的合并 RMSE，避免平均 Loss 抵消不同域的误差。
- 后端：Python / matplotlib，沿用用户明确选择。无 R 或 AI 图像生成。
- 输出：183 mm × 100 mm；可编辑文字 PDF/SVG，600 dpi PNG 和 LZW 压缩 TIFF；最小文字 6 pt。
- 数据：同级目录的 `../metrics_aggregate.csv`；只展示两种不含质量分数的完整配比模型、四种修正和五个非训练表。排除训练表是因为图的目标是校准与跨表评价；含 Q 的消融由实验结果表完整保留。
- 统计：每个点是该数据表的确定性预测误差汇总，不是多种子或多次实验的均值，因此不配造出的误差条，不作显著性检验。样本数是配方行数，13 个响应并非独立重复。
- 风险：A8/A9 参与校准，A10/A11 是回顾性评价，A12–A15 是题目给定估算目标；横轴为数据表类别，等距排布不表示实际规模间距。

## 复现

从仓库根目录运行：

```bash
python scripts/q1_s03/plot_mixture_scale_ablation.py --run experiments/runs/q1-mixture-scale-ablation-20260925-r01
```

脚本检查每个面板 4 × 5 个组合唯一且完备，输出可直接追溯到汇总指标的 `source_data.csv` 和 SHA-256 清单。`QA_notes.md` 记录实际渲染核验结果。

## 中文图注

图 1 | **完整配比模型的规模修正与跨表误差。** a，ilr-Ridge 配比模型；b，二阶 Ridge 配比模型。灰色方形、蓝绿色圆形、紫色菱形和橙色三角形分别表示不加规模项（C0）、全局对数规模修正（C1-global）、逐域对数规模修正（C1-domain）及配方条件化的规模修正（C2）。两种基础模型使用 A4/A5 的配比及 13 个 Loss 响应拟合，不使用质量分数。纵轴为全部样本与 13 个响应的合并 RMSE，即平方误差求平均后开方；越低越好。A6/A7、A8/A9、A10/A11、A12/A13 和 A14/A15 分别有 256、256、64、63 和 63 个配方。A6/A7 为同规模评价；A8/A9 与 A6/A7 的配对差异用于修正标定，因此其修正后性能属于校准内评价；A10/A11 为回顾性跨规模评价。浅灰区域的 A12–A15 使用题目给定的估算 Loss，不代表真实 10B/70B 训练试验。横轴仅表示数据表类别，点的微小横向偏移用于避免重叠，没有实际规模含义。各点为固定模型在整表上的误差汇总，不附代表重复实验变异的误差条，也不进行显著性检验。源数据见 `source_data.csv`，完整指标见 `../metrics_aggregate.csv`。
