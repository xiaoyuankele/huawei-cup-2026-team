# Q2 transfer improvement experiment

See [report.md](report.md) for methods, results and scope. Reproduce with `python scripts/q2_transfer_improvement.py` from the repository root.

Frozen plan: [experiment plan](../../../docs/problem/q2-transfer-improvement-experiment-plan.md).

B2 offset correction and A60M calibration improve held-out predictions beyond simple baselines. A1B does not demonstrate incremental mixture transfer. Q mappings remain assumptions; no joint A-B experiment has been created. Full-target refits are distinguished from nested-group validation predictions. Original v1 parameters remain unchanged.
