# E2 领域替代与互补：条件分析报告

task_id: T-Q2-E2。计算 RUN_COMPLETE；交付 REVIEW_BLOCKED。本轮回答了有限替代的可行范围和模型内效应，并明确当前结构不能给出真实领域互补的证据。

## 1. 对象、单位和公式

输入固定为 v1 模型、A4 的 512 个17域配方及 TOPSIS/soft 两个质量轴。只读取 dataset、index 和17个 p 列，没有读取观测 Loss，没有新拟合。N=1B、D=100B 是计算锚点，不代表存在该规模下的联合实验。质量项沿用半合成来源及假设映射的限制。

令 d=e_i−e_j，含义是在总数据量固定时，从领域 j 移出 δ 的配比并给领域 i。δ=0.01 是 **1个百分点**，不是原领域规模的1%。残差配比为 r=p−p0−v(QA−QA0)，QA=qᵀp。

在质量映射内部，定义 s=0.9/(Qmax−Qmin)，冻结模型关于配比的梯度为

\[
g=c\lambda_Qs q+\lambda_p[w-(w^\top v)q],\qquad
\Delta L=\delta(g_i-g_j).
\]

质量贡献为 δcλQ s(q_i−q_j)，剩余配比贡献为 δλp[(w_i−w_j)−(wᵀv)(q_i−q_j)]。
ΔL<0 代表该条件模型预测 Loss 下降；剩余配比贡献不是质量已被因果控制后的独立领域效应。

## 2. 有限替代范围

对全部272个有向领域对，求解 max δ，满足 Pᵀa=p0+δd、a≥0、1ᵀa=1。原始/对偶证书均保存。
计算采用最优边界的99%作为保守上限，使预测端点保留正的凸组合权重。

| 替代幅度（百分点） | 99%安全上限内的有向替代数 / 272 |
|---|---:|
| 0.1 | 272 |
| 0.5 | 256 |
| 1 | 224 |
| 2 | 165 |
| 5 | 117 |

安全上限的最小值、中位数、最大值分别为0.218892、4.067644、11.829272个百分点。
这说明局部微小导数不能直接推广成任意大幅度的配比建议。训练凸包是配方特征支持，不是性能验证，也不是 N、D、Q、p 的联合支持。
未通过99%规则的目标行保留，Loss变化列留空；这不自动证明它在数学凸包外，因为边界另留有1%安全余量。真实LP边界在 support 表中单独提供。

每个方向还计算安全上限的25%、50%、100%，两质量轴合计4352行有限替代记录。
所有已支持端点的冻结预测变化、解析梯度及质量/剩余配比贡献之和一致。原始/对偶误差的检查容差为2×10⁻⁸，预测分解容差为2×10⁻¹⁰ Loss。

## 3. 方向对桥接假设的依赖

固定 λQ=λp=1，136个无序领域对中，124个在两质量轴下方向相同，12个相反。这复现了E1结果；不是新的外部验证。

预设 λQ、λp∈{0,0.5,1}，结合两质量轴共18组。排除两项同时关闭的2组，剩余16组中，107/136个领域对有正负翻转，27/136个在所有组保持严格同号，另2个含中性但无翻转。
后两对为 pubmed_central—pubmed_abstracts、ubuntu_irc—hackernews；它们在某些纯质量场景中为零效应。

**107/136包含关闭某一分项的宽压力情景，不能解释成经验概率或校准系数置信区间。**
作为同一预设网格的补充切片，仅保留 λQ、λp都为0.5或1时，翻转为19/136。这一切片是描述性补充，不用于事后选择“最好”强度，不改变冻结参数。
因此，部分方向的确定性高度依赖质量与剩余配比如何相加；当前证据不足以发布全局领域优劣或数据采购建议。

## 4. 互补为什么不能由本轮确证

在固定总量下，任取共同供给领域 k 与不同受给领域 i、j，构造
\(p_{10}=p_0+h(e_i-e_k)\)、\(p_{01}=p_0+h(e_j-e_k)\)、\(p_{11}=p_0+h(e_i+e_j-2e_k)\)。
定义四角交互差

\[
I=L(p_{11})-L(p_{10})-L(p_{01})+L(p_0).
\]

在这个明确的供给领域和总量约束下，−I为额外的组合收益：I<0表示预测收益超过单独变化之和，I>0则相反。不能将此定义不加条件地等同于经济学中的跨价格替代弹性。

全部17×C(16,2)=2040种设计、两个质量轴共4080行均提供四角凸组合见证。最大|I|为8.88×10⁻¹⁶ Loss，低于预设10⁻¹⁰数值零阈值。
**这是模型内部仿射结构的数学结果，并非4080次真实训练，也不能证明真实领域不存在互补。** 当前v1在这一区域的二阶交互被结构固定为零，无法利用这些计算识别真实互补强度。

## 5. 截断引起的表观交互

以17个纯领域顶点为基点，遍历双受给方向及0.1、0.25、0.4的配比变化，得到12240行压力计算。所有纯顶点基点都超过对应训练域配比的最大值，因此在A4凸包外；这些行单独保存，不与支持内结果混用。

其中2150行有非零I，1075行为负、1075行为正，最大|I|为0.00938685 Loss。全部非零差异可由
\(c[T(Q_{11})-T(Q_{10})-T(Q_{01})+T(Q_{00})]\)
解释，最大剩余误差为2.22×10⁻¹⁵；剩余配比项的四角差为零。
所以不能把截断造成的折点解释成数据领域互补机制。这是实现压力测试，不是训练支持内的现实预测。

## 6. 题目覆盖与证据等级

| 题目内容 | 本轮交付 | 仍缺什么 |
|---|---|---|
| 不同领域数据替代 | 有向替代矩阵、可行幅度、有限效应与分解、假设敏感性 | 同一N/D/评估口径下的独立训练对照 |
| 不同领域数据互补 | 约束明确的四角定义、结构为零的核验、截断伪交互隔离 | 足够多可识别的联合配比观测与预留验证组合；可表达交互的模型 |
| 模型有效性 | 线性规划证书、预测分解、与E1接口一致、重跑一致 | 这些检查不等于外部泛化、因果识别或完整A—B联合有效性 |

若后续验证真实互补，需要在固定N、D和验证集下，对可行四角配方做真实训练，保留重复训练以估计波动，明确质量随配比的变化；若要区分独立质量效应，还需额外设计质量变化与配比变化可分的对照。之后才比较交互模型与加性基线，并使用未参与选择的配方组合检验。
