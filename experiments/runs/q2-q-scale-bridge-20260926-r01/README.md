## 4. 冻结 M1 下的尺度后果（未重拟合）

用 `q2-m0-m1-20260925-r01:M1.fit_B6` 的冻结参数，把映射后的 `q` 代回
`L = E + A·N^(−α) + B·D^(−β) + G·(1−q)`。
反事实定义：**在同一 (N,D) 上下文下，问题一锚点质量从 p05（42.8893）升到 p95（68.9340）**。

中位 (N,D) 单元（N = 1.0 B, D = 150 B）上的结果：

| 映射 | q 基线→上界 | Δq | ΔLoss | 相对降幅 | ε_q(基线) | ε_q(上界) |
|---|---|---|---|---|---|---|
| `M1_linear_normalization` | 0.4860 → 0.7204 | 0.2344 | −0.084912 | 3.350% | −0.069453 | −0.106518 |
| `M5_linear_normalization_clamped` | 0.4860 → 0.7204 | 0.2344 | −0.084912 | 3.350% | −0.069453 | −0.106518 |
| `M2_minmax_observed` | 0.3948 → 0.7389 | 0.3441 | −0.124641 | 4.854% | −0.055695 | −0.109550 |
| `M3_robust_quantile_p05_p95` | 0.1000 → 1.0000 | 0.9000 | −0.326023 | 12.189% | −0.013543 | −0.154235 |
| `M4_rank_quantile_isotonic` | 0.1000 → 1.0000 | 0.9000 | −0.326023 | 12.189% | −0.013543 | −0.154235 |

（`ΔLoss` 与 `Δq` 对 `G` 严格线性，故 `ΔLoss = −G·Δq` 精确成立，例如
`0.362247×0.234402 = 0.084912`。）
因为 `ΔLoss` 只由 `Δq` 决定、与 `(N,D)` 无关，所以在全部 46 个 `(N,D)` 单元上
`ΔLoss` 的网格范围与该映射的单一值相同；随 `(N,D)` 变化的是**相对降幅**：
`M1` 为 2.428%–3.929%，`M2` 为 3.531%–5.680%，`M4` 为 8.966%–14.168%。

### 质量弹性 ε_q

按 §4 的无量纲定义 `ε_q = (∂L/∂q)·(q/L) = −G·q/L`，**逐点量，依赖 L 的取值**，故给区间而非均值：

- 中位单元上、**限定 q ∈ [0.1, 1.0]**（B6 拟合区间）内，全部 5 个映射 × 全部问题一锚点：
  **ε_q ∈ [−0.154235, −0.013543]**
- 其中基线锚点（Q1 p05）处：**ε_q ∈ [−0.069453, −0.013543]**
- 其中上界锚点（Q1 p95）处：**ε_q ∈ [−0.154235, −0.106518]**
- 若同时遍历 46 个 `(N,D)` 单元：**ε_q ∈ [−0.183401, −0.009962]**（仍限定在 B6 拟合区间内）

`ε_q < 0` 即质量越高 Loss 越低，方向正常。**在 q 落在 B6 拟合区间的全部 3,726 个点上（共 3,910 个点，184 个越界），ε_q 无一为正。**

### ⚠️ PDF-10 同型陷阱的现场证据：越界后 ε_q 会变成正数

`M3_robust_quantile_p05_p95` 的两尾线性外延会把 q 推出 B6 拟合区间
（实测 `mapped_q ∈ [−0.671138, 1.682993]`）。一旦 `q < 0`，`(1−q) > 1`，M1 的纯度项被
**异常外推**，Loss 被推高，于是 `ε_q = −G·q/L` **变成正数**：

- 共 **184** 个（映射 × 锚点 × 单元）组合越界，其中 **92** 个给出 `ε_q > 0`
  （最大 `+0.082300`，出现在 `M3` 的 `ALL_min` 锚点、q = −0.671138 处）。
- 全部越界组合都来自 `M3_robust_quantile_p05_p95`（其余 4 个映射在所用锚点上都留在区间内）。
- 明细见 `tables/epsilon_q_out_of_range_trap.csv` 与 `epsilon_q_out_of_range_summary.csv`。

**处理判定**：`ε_q > 0` 一律判为**定义域失效**，该点结论作废，
**不得**解释成"质量越高 Loss 越高"。按 §4 的要求，先怀疑自己的定义与定义域，不怀疑数据。
`tables/epsilon_q_rows.csv` 因此带 `epsilon_q_valid` 列，所有上报区间都只统计有效点。

> **PDF-10 明确拒绝**：把有限差分 `ΔL/ΔN` 当弹性、声称"无需乘 N/L"是错误的。
> 本 run 全部弹性都乘了 `N/L` 或 `q/L` 归一化（见 `metrics.json` → `rejected_definitions`）。

## 5. §3.4 反向一致性检验：结果（含负面结果，如实报告）

M1 的 `G·(1−Q_score)` 是线性项，隐含"质量在 `Q_score` 轴上对 Loss 的边际效应恒为 `−G`"。
检验该假设：

| 模型 | R² | RMSE | `(1−Q)` 系数 | 标准误 | RESET p | BP p |
|---|---|---|---|---|---|---|
| A：`val_loss ~ (1−Q)` | 0.1100 | 0.32643 | 0.362247 | 0.054447 | 0.954 | 0.0108 |
| B：`+(log N, log D)` | 0.9381 | 0.08632 | 0.362247 | 0.014398 | **2.33e-32** | 3.89e-4 |
| C：`+(1−Q)²` | 0.1100 | 0.32688 | 0.374732（`(1−Q)²` p=0.954） | — | 0.984 | 0.0108 |
| D：`+(1−Q)²+(log N, log D)` | 0.9381 | 0.08644 | 0.374732（`(1−Q)²` p=0.827） | — | **1.45e-32** | 3.86e-4 |
| E：冻结幂形式 `N^(−α)+D^(−β)+(1−Q)` | 0.9703 | 0.05978 | 0.362247 | 0.009971 | 1.22e-8 | 2.18e-3 |

组内配对检验：45 个 `(N,D)` 单元内 `val_loss` 对 `(1−Q)` 的斜率
**均值 = 0.362247435229，sd = 0.110645**（各单元间差异只是噪声），
与冻结 `G = 0.362247435005` **相差 2.2e-10**。

### 结论（三条，其中两条是负面结果）

1. **M1 的线性形式与 B6 内部结构自洽** —— `(1−Q)` 的系数、组内斜率都等于冻结 `G`（差 < 1e-9），
   二次项 `(1−Q)²` 不显著（p = 0.827）。在"线性于 `(1−Q)`"这一点上，M1 没有被证伪。
2. **但这个检验是循环的，不能当作证实。** B6 是半合成数据，而 M1 正是在这 360 行上拟合的，
   所以"线性成立"部分是生成构造的产物。**该假设在 B6 上不可独立检验** ——
   这是 M1 的**形式局限**，不是坐标换算能修的。A 侧没有任何能与 B6 对照的质量–Loss 观测。
3. **整体形式仍有可检出的设定误差（负面结果）。** 把 `(1−Q)` 单独对 `val_loss` 回归只得
   **R² = 0.110**，即质量项在 B6 的总变异里只占约 11%；补齐 N、D 后 R² 才到 0.938，
   且 RESET 检验仍**显著拒绝**（p ≈ 2.3e-32），Breusch–Pagan 也显著（p ≈ 3.9e-4，残差方差非齐性）。
   按 Q 分箱的残差均值在 ±0.004 内、没有系统弯曲，但 RESET 的拒绝说明
   "线性 + 幂律加和"这一整体形式在 B6 上仍有残余设定误差。
   → **不能声称 M1 是"正确"的模型形式；它只是一个未被证伪、但在 B6 上仍不完美的加和形式。**

**本 run 未为了让 M1 看起来更好而改动模型形式，也未重拟合 M1。**

## 6. 结论边界（哪些稳定、哪些翻转）

### 全映射稳定（可写进论文，作条件性论证）

- `Q_A` 与 `Q_score` 的支撑、形状、离散度都不同，**`Q_A/100` 与 `Q_score` 不可互换**。
- 质量提升 → Loss 下降：**ΔLoss 在 5 个映射下符号全部为负**（`−0.0849` 至 `−0.3260`），
  在全部 46 个 `(N,D)` 单元上都不变号。
- `ε_q` **符号恒为负**（在 B6 拟合区间内 3,726 个点全部为负），量级 `10^-2`，
  即 B6 条件下质量项是弱效应。
- M1 在 `Q_score = 1` 处严格退化为 M0（`G·(1−1) = 0`）。
- 线性形式假设在 B6 上**不可独立检验**（循环性）；整体形式仍有设定误差（RESET 显著）。
- `q` 越出 `[0.1,1.0]` 后 `ε_q` 会虚假变正 —— 这是定义域失效，不是效应（见 §4）。
- 不存在可识别的 `G_bridge`；不存在 A–B 逐行对应。

### 随映射选择翻转（**只能写成条件结论**）

- **Loss 影响的量级翻转：相对降幅 3.35%（`M1` 线性，中位单元 3.350%）↔ 12.19%（`M4` 保序），
  差 3.64 倍。** 翻转点就在"是否按分布对齐"这一选择上。
  （跨全部 `(N,D)` 单元：`M1` 为 2.428%–3.929%，`M4` 为 8.966%–14.168%。）
- 绝对 `ΔLoss`：`−0.0849` ↔ `−0.3260`（相差 3.84 倍）。
- `ε_q` 的基线锚点取值：`−0.0695`（线性）↔ `−0.0135`（保序），相差 5.13 倍。
- **是否越过 B6 拟合区间（最有后果的一处翻转）**：
  `M1`/`M2`/`M3` 在 `Q_A` 超出问题一观测范围时会给出 `q < 0.1` 或 `q > 1.0`；
  `M3` 实测可达 `q ∈ [−0.671, 1.683]`，此时 (1−q) 项被异常外推、
  相对降幅被推到 14.168%（超出 B6 可支持的读数），且 `ε_q` 虚假变正；
  `M4`/`M5` 永不越界，读数被限制在 [0.1, 1.0]。
  因此"问题一最低分域是否还能再降质"、"最高分域是否还能再提"这两个问题的答案随映射反转。

**条件写法示例**（问题三可直接用）：
> 在"问题一 p05 → p95 的质量提升"这一反事实下，若采用保序分位桥接（`M4_rank_quantile_isotonic`）
> 且 `(N,D)` 取 B6 中位单元（N = 1.0 B, D = 150 B），则冻结 M1 预测 Loss 相对下降 12.19%
> （`ε_q` 由 −0.0135 变到 −0.1542）；若改用线性归一桥接（`M1_linear_normalization`），
> 同一提升只对应 3.35%。两者相差 3.64 倍，本 run **不能**判定哪一个更接近真实。

## 7. 停止条件与勘误

### 7.2 `FEEDBACK_REQUIRED`（已触发）：冻结数组标签顺序勘误

`metrics.json` 的 `M1.fit_B6` 是**裸数组**。派发提示词与派发 README 声明其顺序为
`[E, A, B, alpha, beta, G]`；**该声明与生产拟合脚本矛盾**。

- 权威来源：`scripts/q2_m0_m1_explore.py` 第 46 行 `e, a, b, g, alpha, beta = theta`
  → 真实顺序为 **`[E, A, B, G, alpha, beta]`**。
- **真正的质量项系数是 `G = 0.36224743500545836`**；
  派发/README 写的 `G = 0.28280291348008263` 其实是 **`beta`**（D 的指数）。
- 三重独立核对：
  1. 复刻 `fit_model(B6, quality=True)` 逐元素最大绝对差 `1.5e-8`（数值精度级）；
  2. 真实顺序下 B6 SSR = `1.272273`（RMSE `0.059448`），与 `metrics.json` 自身记录的
     `grouped_ND_cell_cv` RMSE `0.0512–0.0669` 一致；声明顺序 SSR = `5.488376`（RMSE `0.155386`），
     差 `4.314` 倍，与自身记录不符；用真实顺序预测 B7 扩展 90 行得 RMSE `0.041596`，
     与 `metrics.json` 的 `B7_extension_metrics.rmse = 0.041596` **完全一致**；
  3. 真实顺序逐行复刻已提交的 `m1_b6_elasticities.csv`（`epsilon_Q_score` 最大绝对差 `9.7e-17`），
     声明顺序最大绝对差 `3.7e-2`。

**处理方式（未违反任何禁令）**：

- **未修改** `metrics.json`、**未重拟合** M1、**未改**任何冻结数值、**未改**任何共享文件；
  只在本地按真实顺序解释数组，并把勘误写进 `discrepancy_report.md`。

- `tables/mapping_effect_G_sensitivity.csv` 同时给出两种 G 下的结果供人工核对：
  用声明顺序的 `G` 会把所有 `ΔLoss`、`|ε_q|` **等比缩小 21.9%**
  （例如线性映射的 `ΔLoss` 由 `−0.084912` 变为 `−0.066290`），
  **但不改变任何符号与任何定性结论**。
- 附带发现（供上游参考，未修改）：`q2-elasticity-audit-20260925-r01/metrics.json` 的
  `full_fit_parameters.M1_B6` 把 `alpha`/`beta` 两个标签写反了；该 run 的**数值**是对的
  （其脚本用了正确的 `[E,A,B,G,alpha,beta]` 解包），只是命名错了。

## 8. 明确不能做什么（`limitations` 逐条）

1. 本工作只建立**尺度兼容**，**未**建立 A–B 逐行对应。
2. **未**把问题一的 `Q_A` 认证为正式质量真值（问题一仍为待验收 `REVIEW` 状态）。
3. **不解除**四个核心阻断中的任何一个。
4. **不产生** `G_bridge` 的可识别估计（全程沿用冻结 `G`）。
5. **未**重拟合 M1（也**未**重拟合 M0）。
6. B6 为半合成数据且被 B7 完全包含，**不**把 B6/B7 当作独立观测；B8 未使用。
7. 映射选择会改变 Loss 影响量级，任何单一映射的数值只能写成条件结论。
8. `ε_q` 是逐点量，只能按分位数/锚点报告，不能压成一个常数。
9. M1 质量项是线性项，其常数边际效应假设无法用 B6 自身证伪 —— 这是 M1 的形式局限。
10. 冻结数组标签顺序与派发声明不一致（见 §7.2），已记录但未擅自改文件。
