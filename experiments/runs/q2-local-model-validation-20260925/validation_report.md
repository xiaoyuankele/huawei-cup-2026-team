# Q2 局部模型验证报告

运行编号：`q2-local-model-validation-20260925`

本轮按分块观测结构验证三个局部模型。A 与 B 没有被按行拼接，也没有把缺失变量的笛卡尔积当作新增观测。

## 1. 规模模块

拟合数据：B1 `pythia_training_log_existing.csv`，1176 条真实训练日志。

模型：

\[
L_{scale}=a+b_N\log N+b_D\log D
\]

拟合系数：

- 截距：3.30095
- `log(N_params_B)` 系数：−0.13586
- `log(D_tokens_B)` 系数：−0.17855

B1 内部拟合 MAE 为 0.0733，RMSE 为 0.1030，R² 为 0.9093。训练均值基线的 MAE 为 0.2524，说明该模型在 B1 内部确实提取了规模变化。

留一参数规模验证中，8 个规模组的 MAE 为 0.057–0.178，最低 R² 为 0.378，最高为 0.882。最小规模和最大规模的误差更大，说明端点外推风险较高。

外部验证显示源间偏移明显：

| 数据 | 模型 MAE | 训练均值基线 MAE | 解释 |
|---|---:|---:|---|
| B2 Cerebras | 1.368 | 0.968 | 存在明显模型族/数据口径偏移 |
| B4 跨族基线 | 0.475 | 0.362 | 当前规模模型未优于简单基线 |
| B5 文献数据 | 0.225 | 0.390 | 对文献数据有一定泛化能力 |

结论：B1 规模模块在本族数据内有效，但不能把 B1 的绝对 Loss 标尺直接迁移到所有 B 数据源。需要保留数据源偏移或分层校准。

## 2. 配比模块

拟合数据：A4/A5 的 512 条真实 1M 配方—Loss 记录。

模型：对 13 个领域 Loss 分别拟合一阶 Ridge 混合模型。为处理配比闭合约束，去掉一个配比列作为参考。

| 数据 | 模型 MAE | 训练域均值基线 MAE | 解释 |
|---|---:|---:|---|
| A4/A5 训练集 | 0.403 | 0.643 | 配比解释了部分域间差异 |
| A6/A7，1M 外部验证 | 0.386 | 0.619 | 同规模配比预测有效 |
| A8/A9，60M 外部审计 | 1.514 | 1.524 | 主要受规模偏移影响，不能单独归因于配比 |
| A10/A11，1B 外部审计 | 3.191 | 3.119 | 绝对预测失效，存在明显尺度和 Loss 标尺差异 |

结论：配比模块在同一 1M 规模的 A6/A7 上有预测价值，但不能直接把 1M 配比模型外推到 60M 或 1B 的绝对 Loss。A8–A11 更适合检验“配比方向是否保持”，不适合直接检验绝对值。

A12–A15 的 Loss 是外推值，本轮没有用于任何拟合。

## 3. 质量模块

模型使用 `log(N_params_B)`、`log(D_tokens_B)` 和 `Q_score` 预测 `val_loss`。

注意：B6 的 360 行全部包含在 B7 的 450 行中，因此不能把完整 B6→B7 结果当作独立外部验证。本轮改用 B7 中不出现在 B6 的 90 个新增 Q 水平作为非重叠测试，并在 B7 内按 Q 水平留一验证。

| 训练 → 测试 | 模型 MAE | 训练均值基线 MAE | R² |
|---|---:|---:|---:|
| B6 → B7 新增 Q 水平（90 行） | 0.0606 | 0.2597 | 0.9404 |
| B7 留出单个 Q 水平（每折 45 行） | 0.0603–0.0782 | 0.2560–0.3193 | 0.8780–0.9528 |

B6 的非重叠 Q 水平验证和 B7 的按水平留出验证中，质量模块明显优于均值基线。固定 `(N,D)` 的组内方向检查为：

- B6：45/45 组中，质量越高 Loss 越低；
- B7：45/45 组中，质量越高 Loss 越低；
- B8：150/150 组中，质量越高 Loss 越高。

结论：主质量效应暂时只能由 B6/B7 支持，B8 必须作为方向冲突和外推敏感性结果单独报告。

## 4. 当前可以声称什么

可以声称：

1. B1 内部存在可预测的规模效应；
2. A4/A5 到 A6/A7 存在可重复的同规模配比预测能力；
3. B6/B7 支持一个稳定的质量响应方向和较好的留出预测能力；
4. 不同数据源之间存在显著的 Loss 标尺偏移。

暂时不能声称：

1. 已经由完整观测数据识别了真实的 `L(N,D,Q,p)`；
2. A 的 1M 配比系数可以直接外推到 B 的任意 (N,D)；
3. B8 的质量方向与 B6/B7 可以无条件合并；
4. Q1 的 `Q_A` 与 B 的 `Q_score` 已经完成经验标定；
5. A12–A15 或 B10 的外推 Loss 已被独立验证。

## 5. 下一步组合方式

在上述局部验证通过的范围内，使用：

\[
\widehat L_j(N,D,Q_A,p)
=\widehat L_{scale}(N,D)
+\widehat G(T(Q_A))
+\widehat F_j(p)
+b_{source,j}
\]

组合模型只用于情景预测和资源配置。组合阶段需要对 Q 映射、数据源偏移和规模外推分别做敏感性分析。若要验证 (Q\times p) 或 (N\times Q) 交互项，需要新增同一验证集上的联合桥接实验。

## 6. 组合情景原型

在局部结果基础上，另生成了一个标记为 `SCENARIO_ONLY` 的组合原型：

[组合情景目录](../q2-combined-scenario-20260925)

它包含四种版本：

- `scale_only`；
- `scale_plus_Q`；
- `scale_plus_p`；
- `scale_plus_Q_plus_p`。

质量轴采用 Q1 到 B7 的 affine min-max 假设映射，配比效应使用 A4/A5 相对于训练均值的中心化效应。这个组合原型用于观察敏感性和资源配置情景，不用于宣称完整联合标度律已经被观测数据验证。
