# Nature 风格修订图核对

- 数据：全部 261086 个唯一 ID，七域样本数完全匹配；输入版本哈希一致；所有评分有限且在 0–100；无抽样或删除。
- 统计：与原图的 domain_distribution_summary.csv 字节一致；中位数、均值、Q1/Q3、箱须及每域范围外观测数量不变。
- 密度：每域使用全部样本，统一绝对带宽 1.2 分；400 个网格点覆盖该域实际取值范围；各域按峰值缩放，上下文中明确曲线高度不表示样本量。
- 视觉：逐行核对七个领域的密度、箱线、中位数、均值、n 及右侧中位数；整体核对标题、图例、坐标标签与两条注释，无裁切和相互遮挡。终版拉开标题与副标题间距。
- 统计边界：描述当前样本，不显示未经计算的置信区间或显著性，不将尾部观测视为错误数据。
- 技术：源码检查 20 PASS / 0 WARN / 0 FAIL；PDF 最小字号 7 pt；独立确认页面 183 × 114 mm。PDF/SVG 可编辑文字，PNG/TIFF 600 dpi。
- 字体：中英文采用无衬线组合，字形经预览核对完整。字体子集器对非必要 MERG 表的提示不影响图中文字。

视觉风格参考 nature-figure 的单一主体、低饱和配色、直接标注和紧凑版式原则；不是对某篇 Nature 原图的复制，也不声称经过期刊验收。
